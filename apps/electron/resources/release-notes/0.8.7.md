# v0.8.7 — 本地化、Bedrock 修复与 API 令牌刷新

## 新功能

- **匈牙利语、德语和波兰语翻译** — 新增三种语言，完整覆盖 shell、会话信息弹出窗口、文件部分、富文本输入和岛屿组件的 UI 字符串。波兰语包含正确的复数形式支持。

- **API 令牌刷新端点** — API 类型源现可指定可选的 `renewEndpoint` 用于自动令牌刷新，无需完整 OAuth。适用于发布短期令牌并有专用刷新机制的 API。

## 改进

- **API 源的原始正文支持** — API 源代理现正确处理 `_rawBody` 和 `_contentType` 参数，支持需要发送非 JSON 负载的源（如表单编码、XML）。

## 缺陷修复

- **Bedrock 模型默认值和区域感知** — 纠正了 Bedrock 连接的默认模型列表并添加了区域感知推理配置文件解析，修复了初始模型选择失败并显示"模型标识符无效"错误的问题。现在自动过滤掉缺少所需 `us.` 推理配置文件前缀的裸 Claude 模型 ID。（修复 #536，部分解决 #528）

- **模型下拉滚动** — 下拉子菜单（如模型选择器）现可在列表超出视口高度时滚动。（修复 #527）

- **工作区文件访问** — 现在可以正确打开工作区目录下的文件，修复了"无法打开代码文件"错误。（修复 #526）

- **退出时服务器锁释放** — 应用退出时正确释放服务器锁文件，加强了陈旧锁检测以防止崩溃恢复时"另一个实例正在运行"误报。

- **过时重连会话刷新** — 将过时重连会话刷新移入事务性原子操作，防止睡眠/唤醒重连后可能导致消息丢失的竞争条件。

## 破坏性变更

- 无。
