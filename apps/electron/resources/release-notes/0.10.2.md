# v0.10.2 — 链接型标签、连接账号信息可见、提示词缓存修复

## 新增功能

- **标签新增"链接"值类型** — 标签值在原有 字符串/数字/日期 之外新增 `link` 类型。链接值渲染为可点击的小徽章（展示时去掉 URL 协议前缀），点击在外部浏览器打开，值弹窗里还提供键盘可达的"打开链接"操作。该类型贯通 zod schema、CLI 与 agent 提示词层，会话列表、聊天展示、输入框徽章中表现一致，并附完整的校验/格式化/解析测试。

- **每个 OAuth 连接显示其实际解析到的账号与组织** — "设置 → LLM 连接"现在会显示每个 Claude OAuth 授权实际对应的身份（"邮箱 · 组织"），来自令牌交换响应并持久化在连接上。当同一工作区的两个连接解析到**同一个**账号（共享配额，以前不可见的错配）时，会显示琥珀色警告。本条还顺带修复了一个隐蔽 bug：`updateLlmConnection` 之前按硬编码字段白名单重建连接，每次保存都会静默丢弃白名单外的字段——现在身份字段会完整保留，并有往返测试覆盖。修复 #838。（说明：U Agents 的 U-API 连接不使用 OAuth，此界面变化对你不可见，但白名单修复让连接字段的保存更可靠。）

- **点击"停止"后恢复你最后发送的消息** — 点击停止按钮（明确取消，而非重定向或新发送）后，你最后发送的那条消息会复制回输入框，方便修改后重发。该行为是追加安全的：agent 运行期间已输入的草稿会保留，恢复的文本追加在草稿之后。排队未发送的消息仍走原有恢复路径。

## 缺陷修复

- **Pi 路径的提示词缓存不再每轮失效** — Pi 适配器之前把易变上下文（精确到分钟的日期时间、`session_state`、source 状态）拼进系统提示词，而 pi-ai 把系统提示词作为所有历史消息之前的缓存前缀——每轮重新打时间戳导致 `cacheRead` 每轮归零（使用 DeepSeek V4 等非 Claude 模型时尤其明显）。`PromptBuilder.buildContextParts` 现在拆分为易变/稳定两部分：Pi 路径只把稳定块（工作区能力、工作目录）留在缓存前缀，易变块移到用户消息尾部，与 Claude 路径既有做法对齐；Claude 路径字节级不变。修复 #862。（**对 U Agents 用户这是本版最实惠的修复**：通过 U-API 使用 DeepSeek 等模型时缓存命中恢复正常，多轮对话的 token 消耗显著下降。）

- **"接受计划"下拉箭头随展开状态旋转** — 两个接受计划触发器都经 Radix `asChild` 渲染，`data-state="open"` 落在宿主 `<button>` 上而非内层箭头 `<svg>`，自作用域的旋转样式从未生效。旋转现在通过按钮上的命名组（`group/accept` + `group-data-[state=open]/accept:rotate-180`）作用。修复 #840。

## 备注

- 本版核心价值是**提示词缓存修复**：走 OpenAI 协议的非 Claude 模型（DeepSeek、Kimi 等）此前每轮对话都重新计费全部上下文，修复后多轮会话的成本回到正常水平。
