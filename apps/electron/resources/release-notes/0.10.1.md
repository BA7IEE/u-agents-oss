# v0.10.1 — Opus 4.8 成为默认模型、会话标题跟随界面语言、macOS 仅支持 Apple Silicon

## 新增功能

- 无。

## 改进

- **Claude Opus 4.8 成为默认 Opus 模型** — 底层 Claude Agent SDK 升级到 0.3.154，Opus 4.8 取代 4.7 成为 Anthropic 直连路径的默认 Opus（4.7 仍可选）；已停用的 Opus 4.6 从模型选择器移除。已有的 Opus 4.7 默认配置自动迁移到 4.8，旧的 4.5/4.6 选择迁移到当前可用的最佳 Opus。Bedrock 映射、Pi 回退处理、迁移测试、文档与界面示例同步更新。（说明：U Agents 的 U-API 连接模型清单由你自己管理，**不受此自动迁移影响**。）

## 缺陷修复

- **会话标题跟随"设置 → 外观"选择的语言** — 主进程的 i18n 实例没有语言探测插件（Node 环境没有 `localStorage`），重启后始终停在英文回退值，导致标题生成（`generateTitle` / `refreshTitle`）和系统提示词里的"偏好语言"一直输出英文，即使界面已设为中文。现在所选界面语言会持久化到内部校验字段 `uiLanguage`，主进程启动时据此恢复；渲染进程也会在升级后首次启动时把当前语言推送给主进程，无需重新选择。部分解决 #815 与 #738。

- **预览块滚动时文本选区高亮不再漂移** — 在可滚动的 `markdown-preview` 块（`max-h-[400px] overflow-auto` 容器）里选中文本并追加提问后，黄色选区高亮和编号气泡会锚定在原始坐标上，随滚动漂离文本。现在通过捕获阶段的滚动监听在任意嵌套滚动时重算覆盖层几何（仅坐标的快速路径配合 `requestAnimationFrame` 合并，无标注时直接短路），让高亮始终贴住文本。查看器的标注路径同步修复。

## 破坏性变更

- **macOS Intel (x64) 构建停止提供 — 仅支持 Apple Silicon** — U Agents 的 macOS 版本自本版起仅提供 Apple Silicon (arm64) 构建，不再支持 Intel 芯片的 Mac；x64 `.dmg` 不再产出（v0.10.0 是最后一个含 Intel 构建的版本）。Apple Silicon (M 系列) Mac、Windows、Linux 不受影响。

- **旧 `language` 偏好字段移除** — `preferences.json` 里可自由编辑的 `language` 文本字段被内部校验字段 `uiLanguage` 取代，由"设置 → 外观"驱动。旧配置文件仍然兼容（读取时自动清理过期的 `language` 键），无需任何手动操作。`update_user_preferences` 工具不再接受 `language` 参数。

## 备注

- 对中文用户最直观的变化是**缺陷修复第一条**：重启后新会话的标题终于直接是中文，不再需要手动切一次语言。
- 如果你还在使用 Intel 芯片的 Mac，请停留在 v0.10.0 版本；后续版本将不再提供 Intel 安装包。
