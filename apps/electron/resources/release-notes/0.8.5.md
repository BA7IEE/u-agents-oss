# v0.8.5 — 多语言支持与 Pi SDK 升级

## 新功能

- **多语言支持（i18n）** — 整个 UI 现已本地化。附带**英语**、**西班牙语（es）**、**简体中文（zh-Hans）**和**日语（ja）**——超过 1,050 条翻译字符串覆盖每个页面、菜单、toast、工具提示和对话框。在设置 > 外观中切换语言。会话标题和 AI 响应也遵循所选语言。

- **Pi SDK 升级（0.56.2 → 0.66.1）** — 跨越多个上游版本的主要升级。由于上游修复，**GLM 5**、**GLM 5.1** 和 **Minimax 2.7** 等模型现应正常工作。同时获取：Bedrock 限流不再误识别为上下文溢出、Anthropic HTTP 413 检测用于压缩/重试、Z.ai 工具流式支持、OpenAI 流式修复，以及 bash 输出截断修复。（修复 #503，解决 #513）

## 改进

- **规范语言注册表** — 添加新语言现为单文件更改。注册表自动派生所有语言代码、显示名称、i18n 资源和 date-fns 语言环境。

- **统一语言设置** — 从偏好设置中删除重复的自由文本"语言"字段。外观语言下拉菜单现为 UI 语言和 AI 响应语言的唯一事实来源。

- **i18n 开发者工具** — 预提交钩子捕获暂存 `.tsx` 文件中的硬编码英文字符串。语言环境 parity 测试确保所有翻译保持同步。`localize-agents` skill 自动添加新语言。

## 缺陷修复

- **PC 唤醒后会话消息丢失** — 睡眠/唤醒后，如果服务器子进程死亡，消息丢失，内容区域显示为空。通过重试逻辑、延迟加载回退和活跃会话消息重新获取修复。

## 已知限制

- **无头服务器响应为英语** — 当使用连接到远程无头服务器的 WebUI 时，UI 完全本地化（基于浏览器语言），但 AI 代理仍以英语回复。会话标题也以英语生成。无头服务器的按客户端语言支持将在未来版本中添加。

## 破坏性变更

- 偏好设置中的自由文本"语言"字段已移除。使用设置 > 外观中的语言下拉菜单代替。现有的带有 `language` 字段的 `preferences.json` 文件将被安全忽略。
