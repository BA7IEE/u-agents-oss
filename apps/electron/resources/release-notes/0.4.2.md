# v0.4.2 — Copilot 支持、Mermaid 重构与数据表

主要功能添加，包括 GitHub Copilot 作为替代提供商、完全重建的 Mermaid 图表引擎、原生数据表和众多稳定性修复。

---

## GitHub Copilot 支持

- 添加 GitHub Copilot 作为带完整 OAuth 认证的替代 LLM 提供商
- 用于配置和切换提供商的新连接屏幕
- Claude、Copilot、OpenAI、Ollama、OpenRouter 和 Vercel 的提供商特定图标
- 切换提供商时的会话锁定警告

## 原生数据表与电子表格

- 用于可排序、可过滤数据显示的新 `datatable` 块
- 带导出支持的 Excel 风格网格的新 `spreadsheet` 块
- 用于通过脚本处理大型数据集的 `transform_data` 工具
- 通过 `src` 字段支持 20+ 行数据集的文件备份表

## Mermaid 图表引擎重构

- 用 ELK 替换 Dagre 布局引擎以获得更好的图表布局
- 改进边缘路由、捆绑和方法方向
- 所有图表类型的多行标签支持
- 带圆形、菱形、六边形、 stadium 和状态形状的新形状系统
- 带 ANSI 颜色支持的 ASCII 渲染改进
- 更好的子图方向覆盖和断开图处理

## 连接与提供商改进

- 改进 LLM 连接配置屏幕
- 更新为 Claude Opus 4.6 作为默认模型
- OAuth 令牌刷新改进
- API 源的多头认证支持

## Codex 集成修复

- 修复打包应用中捆绑 Codex 二进制文件路径解析
- 在 Windows 上将 codex.exe 移到 extraResources 以防止 EBUSY 错误
- Codex 会话的技能内容注入（不再依赖原生发现）
- OAuth 会话的静默失败和标题生成修复
- 构建验证现检查 SDK 捆绑阶段的 Codex 二进制文件

## 缺陷修复

- 修复使用 shell.openExternal 的 OAuth 浏览器启动 ENOENT 错误
- 修复工作区主题在工作区切换时不更新
- 修复打包应用中的 dock badge 和窗口图标路径
- 修复 Sentry 仅发送控制台错误而非警告
- 修复 PowerShell 安装脚本使用 YAML 清单
- 修复渲染器在浏览器捆绑包中导入 Node.js fs 模块
- 修复会话持久化中的元数据竞争条件
- 整合大型响应处理

## 依赖更新

- 升级 claude-agent-sdk 到 ^0.2.37
- 升级 electron-updater 到 ^6.8.0
- 添加 elkjs 用于图表布局

## 构建与基础设施

- 默认工作区源配置
- 通过代理 SDK 基础设施统一标题生成
- 移除已弃用的 PlanningAdvisor
- 移除无头模式（合并到主代理流程）
