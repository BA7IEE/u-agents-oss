# v0.7.1 — 稳定性与可靠性

---

## 改进

- **Pi 代理引擎 0.56.2** — 从 0.55.0 更新，带 GPT-5.4 支持（openai、openai-codex、azure-openai-responses）、GitHub Copilot 的 gpt-5.3-codex 回退、Mistral 原生对话集成和 OpenCode Go 提供商支持

- **自动化会话标题** — 自动化发起的会话现使用自动化名称作为会话标题，而非截断的提示片段；这些会话跳过 AI 标题生成（861a5974, 79b9ebb4）

- **CLI validate-server** — 为 CI 环境添加 `--disable-spinner` / `--no-spinner` 标志；validate-server 在不存在时自动引导临时工作区和 LLM 连接（84b3378c, 1ea478d7）

## 缺陷修复

- **分支创建可靠性** — 修复 SDK 的 `ProcessTransport` 的 `ERR_STREAM_WRITE_AFTER_END` 使分支创建陷入无限加载状态的竞争条件；为挂起的预检查询添加 15 秒超时和基于中断的取消（8ff37102, 0dc1d2e6）

- **Base64 误报** — 用严格的规范化管道（字符集正则、规范化、自动填充、往返验证）替换启发式 base64 检测，消除英文文本和其他非 base64 内容的误报。修复 (#344)

- **跨机器会话恢复** — 持久化清除的 `sdkSessionId` 以在会话过期恢复时，防止跨机器同步会话时重复的过时 ID 失败。修复 (#342)

- **自动更新期间 Spawn ENOENT** — 使用结构化错误字段 + 正则回退检测自动更新期间的 app 捆绑包交换，带有界单次重试。修复 (#268)

- **重新认证时重复 LLM 连接** — 修复 `handleReauthenticateConnection` 中生成新 slug（如 `chatgpt-plus-2`）而非重用现有 slug 的过时 React 闭包；在服务器端添加 `updateOnly` 守卫（b735f9df）

- **Codex 令牌过期** — Pi/Codex 认证过期错误现通过类型化错误 auth 重试管道而非显示为红色错误消息；全局刷新互斥锁防止跨会话令牌刷新竞争（1d85bc87）

- **设置"立即检查"卡在 0%** — 统一设置检查和原生菜单之间的 `autoDownload` 策略，使下载进度事件正确到达（b8ad8c44）
