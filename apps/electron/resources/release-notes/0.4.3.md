# v0.4.3 — Hooks 系统、LLM 工具与稳定性修复

引入了用于自动化应用和代理事件工作流的综合 hooks 系统、用于辅助 AI 调用的新 `call_llm` 工具，以及重要的稳定性修复。

---

## Hooks 系统

- 用于在应用/代理事件上运行命令和注入提示词的新型事件驱动 hooks 架构
- 支持会话生命周期、权限更改、标签更新和调度器刻度的事件总线
- 命令 hooks 执行带基于权限的安全性和沙箱的 shell 命令
- 提示词 hooks 在事件触发时将上下文注入代理对话
- 通过新的 SchedulerService 实现基于 cron 的调度
- 事件速率限制器和失控 hook 进程的 SIGKILL 回退
- 会话元数据作为环境变量暴露给 hook 脚本
- 在提示词 hooks 中引用时源自动激活
- 用于调试 hook 执行的事件日志记录器

## LLM 工具 (`call_llm`)

- 新会话作用域工具，实现用于专业子任务的辅助 Claude 调用
- 支持摘要、分类、提取和分析工作流
- 带行范围支持的基于附件的文件和图像加载
- 预定义输出格式加自定义 JSON Schema 支持
- 用于复杂推理任务的扩展思考模式
- 多个同时调用的并行执行支持

## Codex 改进

- 通过移除第三方提供商选项简化 Codex 连接设置
- 升级 Codex 版本到 craft-v0.4.1

## 缺陷修复

- 修复 Enter 配置为发送键时 Cmd+Enter 发送消息两次（修复 (#212)、(#197)）
- 修复设置导航——选择另一页面后点击"应用"不再失败
- 修复 `update_user_preferences` 替换笔记而非追加
- 修复提示词 hooks 不触发和源自动激活

## 构建与基础设施

- 在 CI 中使用 bun-linux-x64-baseline 以实现非 AVX2 CPU 兼容性（修复 (#218)）
- 重构 hooks：移除遗留 API 和全局状态，添加综合测试覆盖
- 改进配置监视器和源配置验证
