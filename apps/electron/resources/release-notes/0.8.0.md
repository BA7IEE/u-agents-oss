# v0.8.0 — 混合传输、WebUI 与移动端

## 新功能

- **混合本地/远程传输** — 全混合传输层，统一工作区连接状态，确保瘦客户端和混合模式行为一致。包括工作区切换器打开时的健康检查、不可达远程的 CloudOff 指示器，以及通过 `invokeOnServer` 和恢复优先策略的跨服务器会话传输。

- **多个远程工作区** — 支持多个远程工作区的工作区选择器 UI，可通过右键或悬停垃圾图标移除工作区。新鲜远程服务器在首次连接时提示用户命名工作区。

- **浏览器可访问的 WebUI** — 无头服务器现可通过同一端口提供完整 Web UI。使用服务器令牌从任何浏览器登录即可创建会话、管理工作区并使用 Claude 和 Copilot 的 OAuth——无需桌面应用。

- **会话导出/导入** — 发送到工作区 UI 用于在服务器之间传输会话。传输的会话正确继承目标工作区的 LLM 连接。

- **移动 WebUI** — 120% 默认缩放、1.3× 触摸目标缩放、iOS Safari 自动缩放防止，以及使用容器查询的响应式布局重写。改进后退按钮行为、面板标题、紧凑模式和卡片响应性。（部分解决 #419）

## 改进

- **供应链安全加固** — `trustedDependencies` 白名单阻止未授权安装脚本。在所有 CI 工作流上强制执行 `--frozen-lockfile` 以防止静默依赖解析漂移。

- **远程服务器目录浏览器** — `server:homeDir` 通道使目录浏览器能够针对远程服务器路径工作。

- **连接到服务器 UX** — 重写流程，有两条不同路径：连接到现有工作区或创建新工作区。

- **自签名 TLS 支持** — 远程 `wss://` 连接接受本地和 Intranet 部署的自签名证书。

## 缺陷修复

- **技能/源提及解析** — 提及现解析为语义标记而非被剥离，在代理提示中保留上下文。

- **子进程服务器生成** — 子进程服务器在无头服务器启动前构建，并使用 `process.execPath` 而非裸 `bun` 来定位运行时。（修复 #441）

- **中止时服务器崩溃** — 捕获未处理的 promise 拒绝，防止之前会话中止时服务器崩溃。

- **WebUI 工作区切换** — `switchWorkspace` 是空操作，破坏推送事件传递；现正确路由事件。

- **WebUI TLS 拒绝** — WebUI 在 WebSocket 端口上提供服务，防止浏览器拒绝 TLS 证书。
