# v0.4.4 — Codex 认证重构与稳定性修复

Codex 源认证、OAuth 令牌刷新和会话稳定性的综合修复。本版本解决了持续的认证失败、OOM 崩溃和重连竞争问题。

---

## MCP 与 OAuth 令牌刷新

- 修复 OAuth 令牌刷新死锁，其中过期的源永久卡在 `needs_auth` 直到手动重新认证（dc019c66）
- 修复 `isOAuthSource()` 混淆类型检查与认证状态检查，防止令牌刷新管理器刷新过期令牌（dc019c66）
- 修复 `ensureFreshToken`/`needsRefresh` 不匹配，其中缺失 `expiresAt` 导致每回合无限刷新但跳过循环（7a0f09e1）
- 在 `expiresAt` 未定义时主动刷新令牌，处理无到期日存储的现有凭证（874edf28）
- 当 OAuth 令牌响应缺失时默认 `expires_in` 为 3600 秒，防止令牌永不被刷新（874edf28）
- 成功令牌刷新后恢复认证状态（磁盘 + 内存）（dc019c66）

## Codex

- 修复 MCP 认证头：配置生成器现写入 `http_headers` 而非 `headers`，后者静默丢弃所有 MCP 源的认证令牌（874edf28）
- 会话中认证的源现自动启用并立即对 Codex 可用（b8d358eb）
- 修复 OAuth 会话中刷新和下一个 Codex 回合之间延迟重连的竞争（d190b9b1）
- 加强重连竞争和输出累积以防止死锁和孤立 promise（7a0f09e1）
- 改进 Codex 工具发现和认证失败指导（a5158d66）
- 防止无界工具输出导致 OOM——事件适配器中命令和 MCP 输出在 100K 字符处截断，持久化层 200K 字符安全网（f66241d6）

## Copilot

- 修复打包构建中找不到 Copilot CLI——原生二进制文件现按平台捆绑，解决登录时 `import_meta.resolve is not a function` 错误（eb02eeb9）
- 添加 30 秒超时到 Copilot 认证模型获取以防止无限挂起（修复 (#228)）（c8f46f59）
- 修复 Copilot 拦截器缺失于 Windows 构建管道（fc619f63）

## 缺陷修复

- 恢复 v0.3.5 的自动更新 UI——内联显示下载进度，正确的"重启以更新"措辞（4172405d）
- 解决共享包中的所有 TypeScript 错误（0e911fe8）
