# v0.7.8 — Amazon Bedrock、1M 上下文与错误处理

---

## 新功能

- **Amazon Bedrock 提供商** — Amazon Bedrock 连接的完整 IAM 凭证支持。预注册 Bedrock 提供商模块以避免捆绑动态导入失败，将 IAM 凭证作为作用域子进程环境变量注入，并为 Bun/Electron 兼容性强制 HTTP/1.1。修复 (#400)。解决 (#99)。

- **1M 上下文窗口** — Opus 4.6 和 Sonnet 4.6 现使用 1,000,000 token 上下文窗口。修复 (#424)。

- **入门"稍后设置"** — 用户现可在入门期间跳过提供商选择，稍后配置。修复 (#440)。

- **CLI `--base-url` 支持** — `--base-url` 标志现通过 Pi 后端路由（与桌面 UI 相同的代码路径），而非被静默忽略。

## 缺陷修复

- **网络代理错误** — 来自代理配置错误的 Cloudflare HTML 错误页面现显示有用的错误消息而非原始 HTML。检测有代理和无代理都适用。

- **Streamable HTTP MCP 的 OAuth 发现** — 使用 Streamable HTTP 传输的服务器现正确回退到 POST 进行 OAuth 元数据发现，修复了不支持 `/.well-known/oauth-authorization-server` 上 GET 的服务器的连接失败。

- **计划提交中断** — 抑制 SubmitPlan 打断代理执行后出现的虚假错误消息。修复 (#420)。

- **会话转录持久化** — 中间消息（工具结果、系统事件）现持久化到会话 JSONL，修复重新加载时的转录间隙。

- **自动化历史上限** — 自动化运行历史现上限为每个自动化 20 次运行（全局 1000 次），带运行时压缩，防止无限存储增长。修复 (#439)。

- **通用错误消息** — 从错误消息中移除硬编码的"Anthropic"，使非 Anthropic 提供商看到正确的错误文本。

## 改进

- **Bedrock 凭证流程** — IAM 凭证的单一凭证获取消除了环境变量注入和 JSONL auth 负载之间的竞争窗口。环境变量从用于初始化消息的相同 `getPiAuth()` 结果派生。

- **Pi 代理错误处理** — 提取 SDK 错误映射器，并为 Claude 和 Pi 后端之间的类型化错误 parity 添加专用 `proxy_error` 代码。

- **自动化历史存储** — 将自动化历史重构为专用 `history-store` 模块，带压缩、周期性持久化和测试覆盖。

## 文档

- 添加了**网络代理**参考页面，记录代理配置、NO_PROXY 绕过和故障排除。
