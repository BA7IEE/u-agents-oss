# v0.7.7 — 思考级别、自动化条件与 Windows 修复

---

## 新功能

- **五级思考系统** — 新思考控制：关闭/低/中/高/最大。Anthropic 模型现使用自适应思考而非遗留的基于预算的思考。Haiku 使用正确的 token 预算（6000/8000 而非 31999）。标题生成不再在扩展推理上浪费 token。修复 (#412)。

- **自动化条件** — 新 HA 灵感的条件系统，支持基于时间、基于状态和逻辑（与/或/非）组合，作为触发器和动作之间的可选门控。在自动化详情视图中显示为可读的"如果"部分，带自然语言描述（如"有标签 X"、"权限模式从探索改为全部允许"）。修复 (#405)、(#355)。

- **YouTube 和 Google 搜索控制台**添加为 Google OAuth 服务。

- **并行 `call_llm` 执行** — `call_llm` 调用现跨 Claude 和 Pi 后端并行运行，而非顺序运行。修复 (#294)。

- **服务器端目录浏览** — 文件浏览器现可用于远程/瘦客户端连接，修复文件夹选择高亮。

## 缺陷修复

- **元数据字段泄露到 SDK** — 为 API 注入的 `_intent`/`_displayName` 字段现正确地在到达 SDK 前被剥离，包括 JSON 解析失败时的基于正则表达式的回退剥离和非 SSE JSON 响应的剥离。这导致模型输出额外参数和工具调用失败。修复 (#308)。

- **Figma MCP OAuth 崩溃** — 暴露 `registration_endpoint` 但对未批准客户端返回 403 的服务器（如 Figma）不再使 OAuth 流程崩溃。回退到默认客户端 ID，现为 Figma 兼容性在 MCP OAuth 客户端名称中使用"Claude Code"前缀。修复 (#189)。

- **Windows 上的 OAuth 浏览器窗口** — 修复导致 OAuth 浏览器无法打开的 Claude 认证切换中断语义。修复 (#414)。

- **MCP OAuth 刷新循环** — 需要浏览器授权的 MCP 源不再因返回"令牌已刷新"却从不显示登录浏览器的静默刷新尝试而陷入 `needs_auth` 状态。

- **缺少 `settings:getNetworkProxy` 处理器** — 现可保存网络代理设置。从旧处理器位置移除约 230 行死代码。修复 (#428)。

- **项目文件夹跨工作区共享** — 工作目录历史现限定到每个工作区。修复 (#417)。

- **自定义提供商模型解析** — 修复自定义提供商的模型解析和 SDK 摘要模型。

- **WebSocket 客户端竞争条件** — 修复连接竞争条件并添加连接/断开日志。

- **过时浏览器绑定** — 修复窗口销毁后的过时会话到浏览器绑定；浏览器窗格方法现防御已销毁的窗口。

- **Webhook 历史验证** — 使验证对边缘情况有弹性。

- **网络代理未应用于 API 调用** — 设置中配置的网络代理仅应用于 Electron 主进程，而非进行实际 API 调用的 SDK 子进程。代理环境变量现注入到所有子进程，网络拦截器通过配置的代理路由请求，支持 `NO_PROXY` 绕过。

- **`CRAFT_DEBUG` 环境变量** — 不再被独立服务器忽略。

## 改进

- **统一自动化匹配** — 重构自动化匹配逻辑和条件验证以确保一致性和正确性。

- **移除冗余流程图** — 从自动化信息面板移除 Mermaid 流程可视化；当/如果/然后部分更清晰地描述自动化。
