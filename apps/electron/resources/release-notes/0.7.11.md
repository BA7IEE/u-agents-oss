# v0.7.11 — 1M 上下文切换与 Bedrock 设置修复

## 新功能

- **1M 上下文切换** — 每工作区设置以启用/禁用 Opus 4.6 的 1M 上下文窗口。禁用以节省使用限额。（设置 → 工作区 → 高级）

## 改进

- **自定义端点上下文窗口** — 自定义端点模型现可在其模型配置中指定 `contextWindow`，而非硬编码为 128K。（部分解决 #448）

## 缺陷修复

- **Bedrock 设置表单** — 修复使用 Pi API 密钥流程时 Bedrock 连接设置失败并显示"请输入有效 API 密钥"的问题。Pi 模型层下拉菜单在到达 Bedrock 处理器前拦截了提交。（修复 #451）

- **Sonnet 1M 上下文** — 从尚未支持的 Sonnet 4.6 移除 `[1m]` 后缀，防止潜在的限流问题。（修复 #453）

- **模型名称截断** — 修复自定义端点模型名称（如 `gpt-5.4`）在下拉菜单中仅显示为"Gpt"的问题。版本号现保留。（修复 #444）
