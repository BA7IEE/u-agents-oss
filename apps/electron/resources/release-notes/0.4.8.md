# v0.4.8 — LLM 工具与插件修复

---

## 新功能

- **`call_llm` 工具** — 调用辅助 LLM 用于专注的子任务，如摘要、分类和结构化提取。跨三个后端支持：Claude、Codex 和 Copilot。支持 API 密钥（完整功能）和 OAuth（基本功能）。支持并行调用、文件附件和结构化 JSON 输出（eb0a3476, fa91af4c, b6e5c85f）

## 缺陷修复

- **插件名称解析** — 当工作区目录名称与 SDK 插件名称不匹配时技能解析失败。现从 `.claude-plugin/plugin.json` 读取实际插件名称（b7904cb7）
- **技能热重载** — 添加工作区技能导致全局和项目技能消失直到重启。所有重载路径现使用 `loadAllSkills` 返回完整三层列表（4172fd82）
- **Codex 事件队列竞争条件** — 当异步 `item/completed` 处理器仍在 `turn/completed` 运行时，工具结果和助手文本可能丢失。通过延迟队列完成直到所有处理器完成来修复（fa91af4c）

## 内部

- Copilot `runMiniCompletion` 现可用——启用 Copilot 后端上的标题生成（fa91af4c）
- Copilot 事件适配器抑制推理/意图事件（fa91af4c）
- `call_llm` 模型徽章显示在 TurnCard 活动行中（8bb4bcd2）
