## 新功能

- **在编码会话中管理 PR**：新增 `pr_status`、`pr_bind`、`pr_unbind` 和 `pr_set_auto_merge` 四个工具，可查询状态、固定或移除 PR，并在用户明确要求时设置 GitHub 自动合并。通过 `gh pr create` 创建的 PR 会自动固定到会话。普通会话和轻量子代理不会显示这些工具。
- **同一会话跟踪多个 PR**：顶部 PR 卡片同时展示当前分支和手动固定的 PR，支持标签切换、溢出菜单和链接复制。其他 PR 出现冲突、审查意见或检查失败时，也会显示状态提示。固定 PR 的修复操作在独立检出目录中进行。
- **自动修复审查意见**：PR 卡片增加“自动”开关，默认关闭。开启后每 5 分钟检查一次，在会话空闲时修复当前分支 PR 的新审查意见。电脑休眠时暂停；存在合并冲突、会话忙碌或处于 Explore 模式时等待。关闭开关、归档、换目录或切换 PR 后，旧检查结果不会启动修复。自动修复会产生模型用量，不会自动推送或回复评论。

## 改进

- 新建工作树时，可在默认目录和最近仓库的父目录中发现最多四层深的 Git 仓库，支持 `~` 路径，并跳过依赖、隐藏目录和工作区数据。
- 切换编码模式时立即打开新会话，对话摘要在后台准备。摘要未完成时，首条消息最多等待 30 秒。
- MCP Source 可设置 `"oauthRelay": false`，使用本机回调完成 OAuth 登录，以兼容拒绝中继回调的服务。

## 修复

- 修复 Pi 编码会话中 PR 工具显示后仍无法执行、创建 PR 后无法自动固定的问题。
- Explore 模式允许查询 PR 状态，继续阻止固定、移除及自动合并等修改操作。
- 当前会话绑定或移除项目、启停 Source 后，下一轮对话会更新工具列表；被移除工具的旧调用会被拒绝。

## 备注

本版本继续使用 U-API 固定模型入口，保留现有 Token、图像生成授权和功能边界。真实网关与计费图像生成的验收结果以候选执行记录为准。
