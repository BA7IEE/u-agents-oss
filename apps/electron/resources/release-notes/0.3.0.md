# v0.3.0 — 精美图表

将 Mermaid 图表渲染为精美的 SVG。超快、完全可主题化、零 DOM 依赖。为 AI 时代构建。

---

## 原生 Mermaid 渲染

U Agents 现使用我们新的开源 Mermaid 渲染引擎 beautiful-mermaid 本地渲染图表。无外部依赖，无浏览器 DOM，纯 TypeScript。

### 为什么这很重要

图表对 AI 辅助编程至关重要。Claude 不断生成 Mermaid 图表——架构概览、数据流、状态机、实体关系。之前这些只是代码块。现在它们是**精美、专业的可视化**。

### 新增内容

**内联渲染**
响应中的 Mermaid 代码块自动渲染为原生 SVG 图表。无需配置。

**全屏预览**
点击任何图表在 Figma 风格的查看器中打开：
- **鼠标滚轮缩放**朝向光标（适应鼠标 vs 触控板）
- **触控板捏合**进行平滑比例缩放
- **点击拖动**平移
- **双击**重置到 100%
- **键盘快捷键**：`Cmd/Ctrl +/-` 缩放，`Cmd/Ctrl 0` 重置
- **预设下拉菜单**：25%、50%、75%、100%、150%、200%、400% 和"缩放到合适"

**图表类型**
- 流程图（`graph LR/TD`）
- 状态图（`stateDiagram-v2`）
- 时序图（`sequenceDiagram`）
- 类图（`classDiagram`）
- ER 图（`erDiagram`）

**主题化**
使用优雅的双色基础——背景和前景颜色通过 CSS `color-mix()` 派生所有视觉元素。图表自动匹配你的 U Agents 主题。

**性能**
100+ 图表在 500ms 内渲染。纯 TypeScript，零 DOM 依赖。

## 应用内预览系统

除图表外，本版本引入统一的内容预览系统。

### PDF 预览

使用 Mozilla 的 pdf.js 的应用内 PDF 查看：
- 带文本选择的基于 Canvas 的渲染
- 页面导航控件
- 后台线程解码

### 图像预览

常见格式的原生查看：
- PNG、JPG、GIF、WebP、SVG、BMP、ICO、AVIF
- HEIC/HEIF 和 TIFF 回退到系统打开

### 智能文件检测

点击文件路径现自动打开正确的预览：

| 类型 | 扩展名 | 行为 |
|------|------------|----------|
| 图像 | png, jpg, gif, webp... | 应用内预览 |
| PDF | pdf | 应用内预览 |
| 代码 | ts, js, py, rs, go, java... | 语法高亮预览 |
| Markdown | md, mdx | 格式化预览 |
| JSON | json, jsonc | 可折叠树视图 |
