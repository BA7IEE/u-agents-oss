# v0.4.6 — HTML/PDF 预览、事件适配器与 OSS 缺陷修复

添加内联 HTML 和 PDF 预览渲染、多后端支持的新统一事件适配器架构、批量会话操作以及多个社区报告问题修复的主要功能版本。

---

## 新功能

- **HTML 和 PDF 内联预览** — 新的 `html-preview` 和 `pdf-preview` 代码块直接在聊天中渲染富 HTML 内容和 PDF 文档，带多项目标签支持和全屏叠加查看（0d22069b）
- **批量会话上下文菜单** — 多选时右键显示批量操作（状态、标签、旗标、归档、删除）而非单会话操作（61759915）
- **动态 Codex 模型发现** — 从 Codex 应用服务器获取可用模型，每 30 分钟定期刷新，回退到硬编码注册表。支持同一提供商类型的多个连接，带唯一 slug 生成（1bcb1083）
- **Mustache 模板引擎** — 带 `{{variable}}` 语法、部分、条件和循环的动态内容渲染新模板系统（a779bf83）
- **源模板** — 源现可通过新 `render_template` 工具发送 HTML 模板以品牌化、一致地渲染其数据。模板使用带自描述元数据头的 Mustache 语法（992a1a50）
- **快速模式功能标志** — 移至共享包以跨包可用（e8295580）

## 缺陷修复

- **macOS 登录启动时会话历史为空** — 在 SessionManager 添加基于 Promise 的初始化门；`GET_SESSIONS` 处理器现等待初始化完成以防止在启动竞争期间返回空结果。修复 (#254)（9ed91fbf）
- **窗口无法在所有面板标题上拖动** — 应用菜单、会话列表面板和面板标题现有一致的拖动区域，因此可以从任何标题区域移动窗口。修复 (#255)（e1ed6619）
- **技能无法自动激活所需源** — 在 SKILL.md frontmatter 中添加 `requiredSources` 字段；技能现声明在代理第一回合前自动启用的源依赖。修复 (#249)（9ed91fbf）
- **聊天中文件链接不可点击** — csv、pdf、png 等文件类型未被链接点击处理器匹配。扩展列表现从 `file-classification.ts` 派生以保持自动同步（a3fa35e4）
- **source_test 对有效 OAuth 令牌报告过期** — 现先尝试令牌刷新再报告过期，匹配实际连接管道行为（7a9bc9d9）
- **中断响应导致 LLM 混淆** — 停止/重定向响应的部分内容现注入上下文注释，使模型不会误解后续消息（8fd1eb7d)
- **工作流选择器和下拉菜单中的图标过大** — 修复 StyledDropdown 和工作流选择器组件中的图标大小（2c917b88, aef87854）
- **Windows Git Bash 路径未保存** — 检测到 `CLAUDE_CODE_GIT_BASH_PATH` 现保存到配置并在启动时恢复（9ed91fbf）
- **每会话环境覆盖竞争条件** — 用每会话 `envOverrides` 替换全局可变 `optionsEnv` 以修复跨并发会话的 `ANTHROPIC_BASE_URL` 竞争（1bcb1083）

## 改进

- **统一事件适配器架构** — 将公共流式/事件逻辑提取到 `BaseEventAdapter`，为 Claude、Codex 和 Copilot 提供后端特定适配器。包括用于有序事件传递的新 `EventQueue`（多个提交）
- **TodoState → SessionStatus 重命名** — 54+ 文件中一致的命名，向后兼容现有 hook 配置和会话文件迁移（e5987124）
- **块间距改进** — 聊天中内容块之间更好的视觉间距（a0402076）
- **转换工具超时改进** — 数据转换脚本更稳健的超时处理（c03011b6）
