# v0.3.3 — 令牌刷新与自动更新修复

MCP 源的自动 OAuth 令牌刷新和主要自动更新可靠性改进。

---

## MCP OAuth 自动令牌刷新

MCP 源的 OAuth 令牌现过期时自动刷新。

### 工作原理

**无缝认证**
当你的 OAuth 令牌过期时，U Agents 在后台使用刷新令牌自动刷新。无需手动重新认证——你的 MCP 连接保持活跃。

---

## 多头认证

API 源现可使用多个认证头。

### 新增内容

**灵活的认证头**
配置需要多个认证头的源（如 API 密钥 + 租户 ID）。见 `~/.u-agents/docs/sources.md` 中的更新文档。

---

## 改进

### 自动更新
- 修复 Windows 和 macOS 上的更新检测
- 正确的 Windows 缓存路径处理（LOCALAPPDATA）
- 检查新版本时检测已下载的更新
- 带可靠按钮可见性的平台感知进度显示
- 在更新可用处理器中检查现有下载

### OAuth 与安全
- RFC 9728 受保护资源元数据发现支持
- OAuth 发现中的 SSRF 加固
- OAuth 边缘情况的更好错误处理
- OAuth 成功页面现包含深度链接以实现更流畅的流程

### 性能
- 并行令牌检查以加快启动
- 延迟加载捆绑文档修复打包应用初始化（(#162)）

---

## 缺陷修复

- **Markdown**：修复 markdown 内容中无效类 HTML 标签导致的 React 崩溃
- **OAuth**：传递完整 MCP URL 到 OAuth 发现以符合 RFC 9728
- **OAuth**：令牌刷新的速率限制以防止过多请求
