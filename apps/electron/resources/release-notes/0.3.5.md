# v0.3.5 — Claude Opus 4.6 与自动更新可靠性

Claude Opus 4.6 模型支持、可靠的 macOS 自动更新进度、自动图像调整大小和技能提及改进。

---

## Claude Opus 4.6 支持

U Agents 现支持 **Claude Opus 4.6**（`claude-opus-4-6`）——Anthropic 最新最强大的模型。

### 变化

- **新顶级模型** — Opus 4.6 来了，现也可在 U Agents 中使用！
- **无处不在** — 设置页面、聊天模型选择器、playground 和 `call_llm` 工具
- **Opus 4.5 仍可用** — 为喜欢它的用户列为"上一代"

---

## 可靠的 macOS 自动更新

升级 electron-updater 到 v6.8.0+，修复 macOS 上的下载进度事件发送。

### 变化

- **真实下载百分比** — macOS 现显示实际下载进度而非不确定的微调器
- **移除约 150 行变通方案** — macOS 文件监视器回退不再需要
- **可靠的更新下载事件** — 更新可靠完成，不再卡住

---

## 自动图像调整大小

大图像现自动调整大小，而非被错误拒绝。

### 变化

- 超过 8000px 尺寸限制的图像**自动调整**以适应 API 限制
- 更好的程序化处理的类型化错误代码（`ImageValidationError`）
- 调整大小不可能时更清晰的错误消息

---

## 技能提及改进

- **工作区 ID 中的点支持** — 技能提及现支持工作区 ID 中的点（`.`），以及空格、连字符和下划线
- **工作区 slug 中的空格支持** — 正则表达式模式更新以兼容 Windows 路径
- **28 个新单元测试**涵盖各种工作区 ID 格式的技能模式解析
