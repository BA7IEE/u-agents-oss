# v0.6.0 — 内置浏览器、文档工具与多面板

---

## 集成浏览器

U Agents 现拥有完整的内置浏览器——无需扩展，无需外部工具。代理可以浏览网页、填写表单、提取数据并截图，全部在应用内完成。

- **应用内浏览器窗格** — 浏览器窗口作为面板与你的对话并排打开，因此你可以实时观看代理导航
- **特权执行批准** — 敏感的浏览器操作需要明确批准，让你保持控制
- **智能截图** — 默认为 JPEG，更快、更小的捕获，带正确的 DPI 缩放
- **完整 CLI 命令集** — 导航、点击、填写、滚动、截图、评估 JS、管理下载等

### 为什么很酷
这解锁了真正的端到端自动化。连接任何数据源，让代理对其操作——填写表单、提交报告、导航仪表板并完全无手地完成多步骤工作流。将浏览器操作与你连接的源结合："从 Amplitude 拉取本周指标，填写内部工具的每周报告表单，并将摘要发布到 Slack。"浏览器弥合了数据和行动之间的差距。

## 文档工具

处理 PDF、Word、Excel、PowerPoint、图像等的内置工具——无需 Python 包或外部依赖。

- **markitdown** — 通用文档到 markdown 转换器（docx、xlsx、pptx、pdf、html、ipynb）
- **pdf-tool** — 提取文本、合并、拆分和检查 PDF 文件
- **xlsx-tool** — 读取、写入和导出 Excel 电子表格
- **docx-tool** — 创建和编辑 Word 文档
- **pptx-tool** — 检查和处理 PowerPoint 文件
- **img-tool** — 调整大小、转换和提取图像元数据
- **doc-diff** — 并排比较两个文档
- **ical-tool** — 读取和解析日历文件

### 为什么很酷
不再需要"安装 pandas"或"pip install python-docx"——文档操作直接工作。让代理"将这 5 个 PDF 合并为一个"、"将此 Word 文档转换为 markdown"、"将此文件夹中的所有图像调整到 800px 宽"，或"比较这两份合同并突出差异"。与源结合用于工作流，如"从 Google Drive 下载最新报告，提取数据表，并为每个行动项创建 Linear 问题。"

## 分支与多面板布局

工作区现支持分支对话和同时查看多个面板。

- **会话分支** — 在任意点分叉对话以探索不同方法，同时不丢失原始线索
- **多面板视图** — 并排打开浏览器、文档和对话
- **新会话列表设计** — 更简洁、更有序的会话管理

### 为什么很酷
并行探索两种不同的实现策略，在编码时保持浏览器面板打开，或并排比较输出。分支意味着你永远不必担心"走上错误的路径"——只需分支并尝试两者。
