# v0.7.12 — Amazon Bedrock、扩展提示缓存与 Docker 服务器

## 新功能

- **Amazon Bedrock 支持** — 完整 Bedrock 认证（IAM 凭证、持有者令牌、环境），自动模型 ID 规范化为美国跨区域推理配置文件。Bedrock 连接通过 Pi SDK 路由以实现可靠的模型解析。（修复 #451）

- **扩展提示缓存** — 新设置将提示缓存从 5 分钟改为 1 小时。通过 Anthropic API 降低 Claude 模型的长时间会话成本。（设置 → AI → 性能）

- **Docker 无头服务器** — 多平台 Docker 构建，用于运行带自动依赖解析的 U Agents 无头服务器。

## 改进

- **1M 上下文切换位置移动** — "扩展上下文 (1M)" 设置从工作区 → 高级移到 AI → 性能以提高可发现性。

- **无头服务器文档** — 重写设置指南，包含安装步骤、启动配置和 TLS 要求。

## 缺陷修复

- **Bedrock 模型 ID** — 通过将裸 Anthropic 模型 ID 映射到 Bedrock 原生美国推理配置文件 ID（`us.anthropic.claude-*`）修复 `400 ValidationException` 和推理配置文件错误。同时修复了配置错误的 `providerType: 'bedrock'` 连接的存储迁移。（修复 #451）

- **Bedrock 捆绑包错误** — 通过在捆绑输出中为 Pi SDK 的两份副本注册 Bedrock 提供商模块修复 `Cannot find module './amazon-bedrock.js'`。

- **分支上下文** — 当 SDK 级分支失败时，父对话现通过 mini 模型摘要作为回退上下文，而非静默丢失历史。（修复 #454）

- **MCP 工具 schema** — 从导致验证失败的外部 MCP 工具输入 schema 中剥离 `$schema` 属性。

- **Pi SDK 压缩竞争** — 防止 Pi SDK 子进程中的自动压缩竞争条件。（修复 #464）

- **MCP 服务器 URL** — 停止错误地将 `/mcp` 附加到 MCP 服务器 URL。

- **拦截器清理** — 网络拦截器现主动剥离缓存 TTL 和 context-1M beta 头以防止与提供商特定处理冲突。
