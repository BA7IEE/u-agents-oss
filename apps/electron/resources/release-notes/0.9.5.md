# v0.9.5 — 紧凑模式 UX 完善 + MCP / 分支稳定性修复

## 新增功能

- **紧凑模式会话行菜单改 vaul drawer** — 紧凑 / 移动布局下，会话行右键/长按菜单不再使用会被 panel 容器裁切的 Radix popover，改用与状态、标签、分享、通讯一致的 vaul drawer 样式呈现。桌面布局的下拉行为完全不变。

- **紧凑模式工作目录选择器改 drawer** — 紧凑布局下的工作目录选择器改用 drawer 呈现路径列表、最近目录、"选择文件夹…"操作，不再需要横向滚动。桌面下拉框保持原样。

- **紧凑布局下输入框可折叠/展开** — 紧凑 / 移动视图下，折叠的聊天输入框现在可以点击展开，方便撰写较长的提示词时不必离开当前会话。

- **紧凑模式 AcceptPlan 选择器改 drawer** — 计划接受界面在紧凑 / 移动布局下改用 drawer，避免操作行被推出可视区。

- **Web UI 移动断点下自动切紧凑模型选择器** — Web UI 的模型选择器在 shell 宽度跨过移动断点时会自动收起为紧凑选择器，与 Electron 桌面端的 container-query 行为对齐。

## 改进

- **抽出共享 `useWorkingDirectoryState` hook** — 路径解析、最近目录、文件夹选择处理逻辑统一抽到一个 hook 里，让桌面下拉框和紧凑 drawer 不会在行为上漂移。

## 缺陷修复

- **基于最新 turn 的分支会话不再丢最后一条 assistant 消息** — Pi 后端的分支会话路径现在在 SDK 追加新消息**之后**才捕获会话锚点，因此从最近 turn 分支出去时不会再截断触发分支的那条消息。

- **stdio MCP `source_test` 给真实诊断而非假超时** — stdio MCP 服务器的 `source_test` 现在在单进程内跑、用一个 stderr 活动 watchdog 来观察启动输出，替代之前任何启动稍慢的健康服务器都会报"Server startup timeout"的假错。

- **并行 `source_test` 不再卡死会话** — 当 source-activation abort 中断 turn 时，同批并行工具的 sibling `tool_result` 现在会先 drain 再让 abort 传播，避免 SDK 留下 orphan `tool_use` ID 永久卡住下一个 turn。

- **AcceptPlan 下拉框定位 + 紧凑视图可见性修复** — 桌面 AcceptPlan 下拉框改用 Radix `DropdownMenu`，修复锚点漂移与 viewport 裁剪导致 action 被推出屏幕的问题。Web UI 紧凑视图现在也真正渲染下拉框（之前藏在 wider-only 分支后）。

- **工具调用结尾的 turn 不再卡"思考中…"** — 与 messaging-gateway 端的同类修复一致：当 Pi agent 输出 intermediate text + tool call 后没有 non-intermediate `text_complete` 就完成时，`groupMessagesByTurn` 现在依据 session 的 `isProcessing=false` 信号关闭打开的 turn，并把 intermediate text 提升为最终回复。修复前这种 turn 会永远停在"思考中…"，必须再发一条消息才能解锁。

- **Messaging gateway `progress`/`final_only` 模式投递最终消息** — 当自动化的最后动作是工具调用（例如代理用工具发了 Telegram 消息后没有干净的 non-intermediate `text_complete`），之前 `progress` 模式会永远卡在"💭 思考中…"且 `final_only` 模式静默。Renderer 现在跟踪最近 assistant 文本（无论 `isIntermediate` 是 true 还是 false），并在 `complete` 时若无干净 final 则回退到它；真正空跑的场景仍然保留状态标签。

- **SDK Agent 子代理活动分组可再次折叠** — SDK Agent 子代理运行的 activity 分组不再扁平渲染，折叠 toggle 行为恢复正常。

## 破坏性变更

- 无。所有变更向后兼容。

## 备注

- **本版主题是紧凑/移动布局的 UX 完善 + MCP / 分支会话稳定性修复**，不引入新功能、不升级底层 SDK（Pi SDK 仍是 `0.73.1`），是一次以打磨 + 修 bug 为主的版本。
- 与 v0.9.4 比，影响面侧重 UI 层（多个 drawer 改造）和 MCP / branching 路径修复；桌面布局的常规视图行为保持不变。
