# v0.8.9 — Opus 4.7 默认

## 新功能

- **Claude Opus 4.7 作为新默认** — Anthropic 于 2026 年 4 月 16 日发布 Claude Opus 4.7，现为应用默认 Opus 模型。现有用户配置在启动时自动从 4.6 迁移到 4.7。Opus 4.6 仍可用，为其保留 Bedrock 条目以保持向后兼容性。

## 改进

- **Claude Agent SDK 升级至 0.2.111** — 带来原生 Opus 4.7 支持及新 SDK 能力：`mcp_set_servers` 带每工具 `permission_policy`、公共 `startup()` / `WarmQuery` API，以及新的 `system/memory_recall` 事件。包括上游安全更新（`@anthropic-ai/sdk` 升级到 ^0.81.0）。

## 缺陷修复

- 无。

## 破坏性变更

- 无。
