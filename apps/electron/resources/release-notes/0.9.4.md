# v0.9.4 — RTK Token 优化、紧凑会话菜单修复、长会话连接稳定性

## 新增功能

- **RTK Bash Token 压缩（可选）** — 在 设置 → AI → 性能 加入对 [RTK](https://github.com/rtk-ai/rtk) 的可选支持。U Agents 仍按原 Bash 命令显示并按权限规则校验；当本机装好 RTK（`>=0.23.0`）且开关打开后，SDK 实际执行的路径会被改写成走 `rtk` 子命令，让常见开发命令的输出在送进模型前被压缩。设置页会自动检测 RTK 是否安装/版本是否过低，没装时显示 **获取 RTK** + **重新检查** 两个按钮；RTK 处理过命令后会显示节省的 token / 效率统计。默认关闭；隐私上，所有 spawn 都强制设 `RTK_TELEMETRY_DISABLED=1` 禁掉 RTK 自带的 telemetry。

## 改进

- **后端打包清理（Pi 整合后死代码精简）** — 删除两后端架构（`ClaudeAgent` + `PiAgent`）收敛后还残留的旧后端打包条目、import 守卫、运行时字段、docblock 注释等。代码库不再含误导的旧后端引用，方便后续后端工作。

## 缺陷修复

- **长会话连接不稳定（1011 keepalive / 1006 disconnect / 证书校验失败）** — 升级底层 Pi SDK 到 `0.73.1`，吸收上游 transport 层修复：WebSocket 建连失败时可以在开始流式输出前回退到 SSE；会话结束时缓存的 WebSocket 也能被正确关闭。这一组修复主要针对长时间运行的 ChatGPT Plus / 长会话场景报告的 `1011` keepalive 超时、`1006` 断连、证书校验失败。

- **紧凑布局下的会话菜单不再裁切嵌套操作** — 在窄/紧凑布局下，聊天标题菜单不再用 Radix 嵌套 dropdown（之前会被 panel container query 容器裁掉），改用 vaul drawer 配合 iOS 风格的单栏 drill-in 展示「状态 / 标签 / 分享 / 通讯」四组操作。桌面布局的 dropdown 行为完全保持不变。同步修复：切换布局时清理桌面 dropdown 的残留状态；drawer 打开期间如果当前会话被导航切换，drawer 内的操作不会跑到错误会话上。

- **快速点击会话标签不再竞态** — 会话菜单共享行为抽到 `useSessionMenuActions` hook；标签切换改成乐观更新，可以叠加快速点击、避开 React Strict Mode 双副作用、切换会话时正确重置。修掉了紧凑布局 drawer 内多标签编辑卡住的问题，桌面与紧凑两种菜单行为也对齐了。

- **技能 "在 Finder 中显示" 真正打开技能目录** — 技能列表、技能详情、技能菜单三个入口的"在 Finder 中显示"现在都打开 `skill.path` 真实目录（之前是合成的 `SKILL.md` 路径，时常失败）。失败时不再静默忽略，而是按平台弹一个 Finder/Explorer 错误 toast。

## 破坏性变更

- 无。所有变更向后兼容。

## 备注

- **RTK 是可选功能且默认关闭**。如果你不熟悉 RTK，**完全可以忽略**——所有 LLM 请求仍然走 U-API 中转，行为与 v0.9.3 一致。
- **底层 SDK 升级**：Pi SDK 从 0.72.1 升级到 0.73.1，主要是 WebSocket/SSE 传输层修复，对你来说**只会感到长会话更稳了**，没有破坏性变更。
