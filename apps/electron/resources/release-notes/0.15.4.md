## 新功能

- 增加可选的 Coding 模式，使用更精简的提示词和会话工具。默认关闭，可以在新会话中开启，也可以设置为工作区的新会话默认模式。
- Coding 模式支持选择已有文件夹或创建独立 Git 工作区。
- Coding 会话顶部显示关联拉取请求的状态，包括检查、评审意见与合并冲突；相关快捷操作会交给当前代理处理。

## 改进

- 升级 Claude Agent SDK 至 0.3.302。
- 调整 Coding 模式的顶部布局，为文件夹与拉取请求状态留出空间。
- Coding、精简代理与内部后台调用不提供付费图片生成工具。

## 修复

- 分离 HEAD 的 Git 工作目录不再显示误导性的分支名称，查询分支信息也不会阻塞界面。
