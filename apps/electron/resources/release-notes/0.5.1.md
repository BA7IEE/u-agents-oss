# v0.5.1 — 自动化

---

## 自动化

自动化（原 hooks/tasks）现拥有完整的管理 UI——无需再手动编辑 JSON 文件。

- **侧边栏面板** — 按类型（全部、计划、事件驱动）浏览、搜索和过滤自动化
- **启用/禁用** — 切换单个自动化开关，无需删除
- **复制与删除** — 克隆现有自动化或移除，支持多选批量操作
- **执行历史** — 每个自动化记录成功/失败到时间线，可在详情页面查看
- **应用内编辑** — 自动化详情页面上的编辑按钮用于快速更改
- **测试运行器** — 手动触发自动化以在实际事件发生前验证其工作

### 提示动作的 LLM 连接与模型

提示动作现可指定要为其创建会话的 AI 提供商和模型：

```json
{
  "type": "prompt",
  "prompt": "Review overnight @github pull requests",
  "llmConnection": "my-openrouter",
  "model": "anthropic/claude-sonnet-4.6"
}
```

`llmConnection` 值是 AI 设置中 LLM 连接的 slug。验证在运行前捕获缺失连接（错误）和模型/提供商不匹配（警告）。

### 配置格式

规范配置文件现为 `automations.json`，格式版本 2。不再加载遗留的 `hooks.json`——重命名并更新以继续使用你现有的自动化。

## 改进

- **所有提供商的 API 源** — API 源（Slack、Gmail）现暴露到 MCP 池，使它们可用于非 Anthropic 后端，如 Copilot、Codex 和 Gemini
- **技能元数据** — `requiredSources` 和 `icon` 字段现显示在技能信息页面（(#290)）
- **自动化列表排序** — 按最近执行排序，以便快速访问活跃自动化
- **`Setup` 代理事件** — 代理初始化自动化的新事件类型
- **Cron 年份显示** — 当运行跨多年时，在下次运行预览中显示年份

## 缺陷修复

- **文件提及** — 聊天消息中的文件和文件夹提及不再被剥离；它们现解析为代理的绝对路径（(#293)）
- **ConfigWatcher 目录** — ConfigWatcherManager 不再在工作目录内创建 `sources/` 和 `skills/` 目录，而是在工作区根目录
- **自动化测试处理器** — 手动"测试"现解析 @提及，启用源，并传递 `llmConnection`/`model`/`permissionMode`（与调度器相同的代码路径）
- **安装脚本** — 直接获取 YAML 清单而非依赖版本端点；多个 PowerShell 5.1 兼容性修复（(#273)）

## 破坏性变更

- **遗留配置移除** — 不再读取 `hooks.json`，也没有自动迁移。如果你有现有 hooks，需要将它们重新创建为新 `automations.json` 格式的自动化。最简单的方式是向代理描述你的工作流——例如"在上午 9 点设置每日站会简报"——它会为你创建配置。完整格式参考见[自动化文档](https://u-agents.u-studio.cn/docs/automations/overview)。
