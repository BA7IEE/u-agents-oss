# v0.7.9 — 可靠的 WebSocket 推送、Copilot 模型重构与 Windows 修复

---

## 新功能

- **可靠的 WebSocket 事件推送** — WebSocket 连接现使用序列号跟踪并在重连时自动重放。事件在服务器端缓冲并在客户端重连时重放，消除网络中断期间的事件丢失。包括过时重连恢复、监视器重新订阅，以及防止双重 `onClientDisconnected` 调用的守卫。

## 缺陷修复

- **Copilot 模型管理重构** — GitHub Copilot 模型发现和同步的完整重写。用直接 HTTP API 调用替换 CopilotClient CLI，添加三层回退链（HTTP API → CLI → 静态目录），并修复模型刷新周围的多个竞争条件。无明确启用策略的模型现被排除，过时的 GPT-4/3.5 模型被过滤掉，陈旧数据不再覆盖良好的模型列表。部分解决 (#418)。

- **1M 上下文激活** — 通过从 beta 头切换到 `[1m]` 模型后缀修复 Opus 4.6 和 Sonnet 4.6 1M 上下文窗口。

- **Windows：VC++ 运行时检查** — 用更好的类型安全、测试覆盖和错误处理加强 vcredist 检测。

- **Windows：二进制文档工具** — 文档转换（`markitdown`、`pdf-tool` 等）和技能资产访问现可在 Windows 上正确工作。

## 改进

- **Windows VC++ toast** — 将缺失 VC++ 可再分发包的阻塞启动对话框替换为非阻塞应用内 toast 通知。

- **Copilot 模型刷新日志** — 添加诊断日志以帮助排查模型同步问题。
