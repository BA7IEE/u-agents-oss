# v0.3.1 — 会话搜索与迷你代理

即时搜索所有会话。用于快速专注编辑的迷你代理。

---

## 会话搜索

使用 ripgrep 支持的全文搜索在对话历史中查找任何内容。

### 工作原理

**快速访问**
按 `Cmd/Ctrl + F` 或点击侧边栏中的搜索图标开始搜索。

**智能结果**
- 仅搜索用户和助手消息（过滤系统噪音）
- 在会话列表中直接显示匹配片段
- 输入时实时高亮匹配

**导航**
- 使用箭头按钮在匹配项之间跳转
- 自动滚动到对话中的匹配文本
- 匹配计数器显示跨所有会话的总出现次数
- 自动展开分页回合以显示更早的匹配

**性能**
- 基于 ripgrep 的搜索，即使数千个会话也能即时结果
- 仅高亮可见匹配以保持滚动流畅

## 迷你代理

用于快速配置编辑的轻量代理，无需完整的 Claude Code 开销。

### 新增内容

**专注编辑**
迷你代理使用针对编辑状态和标签等特定任务优化的精简系统提示。无需不必要的工具或上下文。

**更快更便宜**
可配置为使用更快的模型（如 Haiku）处理不需要完整推理能力的简单任务。

**内联执行 UI**
新的紧凑进度显示显示代理在弹出窗口内的操作：
- 最近 3 个活动及描述
- 正在处理的文件路径和模式
- 成功/错误消息渲染为 markdown

**可拖动弹出窗口**
编辑弹出窗口现带手柄——可拖动到屏幕任意位置。
