# v0.8.4 — 源通用 OAuth、发送到工作区与开发者工具

## 新功能

- **API 源通用 OAuth** — 基于 API 的源现可使用标准 OAuth 认证。通过 RFC 9728（OAuth 授权服务器元数据）自动端点发现，因此你只需提供发行者 URL，其余自动解析。

- **发送到工作区** — 跨工作区一键共享源、技能和自动化新操作。支持单条和批量操作，可一次移动多个资源。

- **打包应用中的开发者工具** — 开发者工具现可通过查看 > 切换开发者工具在生产构建中访问，使无需开发构建即可调试问题更容易。

## 改进

- **OAuth 文档** — 在线文档和 GitHub 源指南中添加了通用 OAuth 设置和自动发现指南。

## 缺陷修复

- **通过 Pi 会话工具不可用** — 会话自我管理工具（`set_session_labels`、`set_session_status` 等）现通过 Pi agent 路径路由时正确工作。（修复 #511）

- **屏幕保持常亮** — 修复了即使禁用保持屏幕常亮设置后屏幕仍保持常亮的问题。（部分解决 #415）

- **远程路由负载翻译** — 嵌套负载对象内部的 `workspaceId` 现为远程工作区路由正确翻译。

- **WebUI 上的自动化加载** — 自动化现通过服务器端 RPC 加载，而非直接文件读取，修复了远程/Docker 设置上的失败。

- **错误卡片按钮损坏** — 错误卡片中的设置和重试按钮现正确连接且功能正常。

- **模型层提示硬编码为 Anthropic** — 模型选择器弹出窗口现使用提供商感知的层提示而非 Anthropic 特定别名，修复了非 Anthropic 提供商的显示问题。

- **API 源的 OAuth 令牌检索** — 修复了 SessionManager 中通用 OAuth API 源的 `getToken` 未连接的问题。

- **OAuth 错误消息** — 改进源中缺少 `api.oauth` 配置块时的错误消息。

- **Linux 资源导入** — ConfigWatcher 现在线上导入后得到通知，修复了 Linux `fs.watch` 兼容性，导入的资源在重启前不会出现。

- **Docker/远程上的发布说明** — 当 Electron 资源路径不可用时，发布说明现回退到 `~/.u-agents/release-notes/`。

- **WebUI 关于页面** — 关于对话框现显示服务器版本，隐藏无关的"立即检查"按钮，"新增功能"在 WebUI 上正确工作。

## 破坏性变更

- 无。
