# v0.7.6 — 自定义端点与 MCP 头

---

## 新功能

- **MCP 自定义头支持** — HTTP 传输的 MCP 源现可在所有请求（发现和工具调用）上发送自定义头。头值通过 `headerNames` 安全存储在凭证存储中。修复 (#410)。（e4af87b0, 8bce7257）

- **validate-server 的 `--workspace-dir`** — `--validate-server` CLI 标志现接受 `--workspace-dir` 以针对特定工作区布局测试预提交的源。（2d135a6f）

## 缺陷修复

- **自定义端点未持久化** — 保存 LLM 连接配置时 `customEndpoint` 字段被静默丢弃，导致自定义 Anthropic 兼容端点在重启时回退到默认 API。修复 (#413)。（09b62551）

- **自定义端点的错误模型 ID** — 自定义端点默认值现使用正确的 Anthropic 模型 ID 而非过时值。（8a3aa4f9）

- **浏览器认证源的 OAuth 刷新循环** — 需要基于浏览器授权的源不再触发会失败和循环的静默 OAuth 刷新尝试。（42d6592a）

- **错误中的硬编码"Claude Max"** — 会话过期错误消息不再按名称引用"Claude Max"。（01517b3d）

## CI / 文档

- **OSS 构建 parity** — 添加平台打包脚本（`build-dmg.sh`、`build-linux.sh`、`build-win.ps1`）和 macOS 权限 plist 到 OSS 同步白名单，使社区贡献者能够构建生产包。解决 (#422)。
