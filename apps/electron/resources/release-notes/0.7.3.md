# v0.7.3 — OAuth 稳定性、后台任务与标题生成

---

## 新功能

- **后台任务 UI** — 工具卡现显示后台任务（代理、任务）运行时的微调器，清楚显示活跃工作的视觉反馈（20352706）

- **改进的标题生成** — 会话标题现使用扩展消息选择和语言感知生成，产生跨语言更准确和自然的标题（835ea942, 55b7830c, 46975ac7）

- **排除过滤器徽章** — Alt/Option 点击过滤项现将它们添加为排除过滤器，在按住 Alt 时显示实时徽章预览（fce25e23, 8a2ebbee）

- **自动化生命周期测试** — `--validate-server` 现包含自动化生命周期测试，捕获自动化管道的回归（19fe11e9）

## 改进

- **MCP schema 转换** — `oneOf`、`anyOf`、`allOf` 和嵌套对象现正确处理转换 MCP 工具 schema 时，减少提供商的"意外参数"错误。部分解决 (#308)（64ae9d69）

- **MiniMax 预设拆分** — MiniMax 提供商现拆分为单独的全球和中国变体，带正确的区域端点。修复 (#386)（d626f732, 5ba42ca3）

- **@文件提及解析** — 聊天输入中的文件提及现包装在语义标记中，使代理能够正确读取和解析它们。修复 (#293)（15d20c1d）

- **自动创建标签** — 自动化引用的标签现自动创建（如果不存在），防止静默失败（76306c0b）

- **多 OS CI 验证** — `validate-server` 工作流现 macOS + Windows + Linux 矩阵运行，启用快速失败（32f4c91e）

- **标题生成语言感知** — 标题更好地反映对话语言。部分解决 (#286)（835ea942, 1892b4c9）

## 缺陷修复

- **虚假 OAuth 重新认证** — 修复了源在成功令牌刷新后触发不必要的重新认证流程的竞争条件，导致连接中断和重复认证提示（b98a2b2d, e101301b, a3264b02, 76bb5388, d8632e30）

- **令牌刷新时 MCP 源断开** — MCP 源现 OAuth 令牌刷新时正确重连，而非保持断开状态（b1b515b2）

- **重新认证菜单交互锁定** — 修复了重新认证菜单可能陷入锁定状态阻止进一步用户交互的竞争条件（34dfc91f）

- **MCP 传输竞争条件** — 修复了连续 SDK 查询可能损坏 MCP 传输层的竞争条件（f7d3f902）

- **代理/任务活动卡住运行** — 后台任务工具活动（代理、任务）不再在底层任务完成或出错时卡在"运行中"状态（6d49ae82）

- **后台任务内存泄漏** — 提取工具帮助函数并修复后台任务通知处理中的内存泄漏（6979d063）

- **前导词剥离回归** — 迭代前导词剥离现处理语言清理中的边缘情况，更可靠地过滤低信号内容（1892b4c9）

- **重复导入** — 移除 `turn-utils` 中遗留的重复 `Message` 导入（0aa7045f）
