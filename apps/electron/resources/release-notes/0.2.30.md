# v0.2.30 — 差异查看器控件、Windows 改进与应用菜单

## 新功能

### 差异查看器控件
- 带拆分/统一视图切换的新差异查看控制栏
- 背景高亮切换以便更容易阅读差异
- 内联统计一目了然显示添加（+）和删除（-）
- 通过 preferences.json 持久化设置（替换 localStorage）

### Windows 特定改进
- Windows 用户的 Git Bash 检测和配置向导
- 自动检测常见安装路径中的 Git Bash
- 自定义 Git Bash 安装的手动浏览选项
- Windows 特定设置的清晰入门指导

### 增强应用菜单
- 带子菜单的完整 macOS 风格下拉菜单
- 标准编辑操作：撤销、重做、剪切、复制、粘贴、全选
- 窗口控件：最小化、最大化、新建窗口
- 视图控件：放大、缩小、重置缩放
- 开发构建中可用的调试子菜单

## 改进

### 跨平台健壮性
- 新 ESLint 规则强制跨平台代码模式
- 路径处理重构为使用平台感知分隔符
- 临时目录处理使用 OS 适当的路径
- Monorepo 路径解析跨平台正确工作

### 构建系统现代化
- 构建脚本从 shell 命令迁移到 TypeScript
- 主进程、预加载、渲染器和资源的独立脚本
- 带 HMR 支持的改进开发服务器
- 更好的可维护性和 Windows 兼容性

### 会话持久化
- 基于异步队列的持久化以实现可靠写入
- 处理生成计数器防止陈旧消息覆盖
- 更健壮的会话状态管理
- 改进的并发操作处理

### UI 打磨
- 所有预览叠加的集中背景样式
- 叠加和进行中状态的视觉改进
- 改进的叠加组件架构
- 差异、代码和终端预览之间更好的一致性

## 缺陷修复

- 修复任务结果清理导致错误的工具嵌套
- 解决会话持久化中的潜在竞争条件
- 修复 monorepo 开发设置中的路径解析问题
