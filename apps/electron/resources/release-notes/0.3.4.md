# v0.3.4 — 技能约定与 Windows 构建改进

支持 `.agents/skills` 约定和主要 Windows 构建可靠性改进。

---

## 支持 `.agents/skills` 约定

技能现可放在 `.agents/skills` 目录中，遵循新兴的跨工具标准。

### 新增内容

**跨工具兼容性**
将你的技能放在 `~/.agents/skills/`，它们将与 U Agents、Codex、Gemini 和支持此约定的其他工具一起工作。你现有的工作区技能继续像以前一样工作。

> 解决 (#171)

---

## 主题配置优先级修复

配置文件主题设置现正确覆盖 localStorage。

### 工作原理

**配置作为事实来源**
当你在 `~/.u-agents/config.json` 中设置 `colorTheme` 时，它现正确优先于 localStorage 中的任何缓存主题。这使得代理可以通过文档化的配置路径修改主题成为可能。

> 修复 (#178)

---

## 改进

### 错误处理
- AI 提供商错误的有用消息（内部服务器错误、api_error），提供检查状态页面的指导（(#166)）
- 自定义模型支持现正确用于摘要——所有内部模型调用使用 `resolveModelId()`（(#168)）

### 技能
- 修复技能提及格式——@ 提及现生成正确的工作区别名格式而非原始 UUID（(#174)）
- 步骤滚动行为改进——"完成的步骤"现滚动到最新步骤

### UI
- 防止 EditPopover 在视口外渲染
- 修复时间显示"60m"而非"1h"
- 在多行用户消息中保留换行（Shift+Enter）

### Linux (Hyprland/Wayland)
- Hyprland/Wayland 可能 IPC 失败的窗口关闭超时回退（(#131)）

## 缺陷修复

- **技能**：修复 @ 技能提及生成错误的 ID 格式（UUID 而非工作区别名）
- **UI**：EditPopover 现保持在视口边界内
- **Linux**：Hyprland/Wayland 环境的窗口关闭超时回退

---

## 构建与 CI (Windows)

Windows 构建可靠性重大改进：

- 捆绑包而非标记为 external 以获得更好兼容性
- 对 Windows bun install 使用 `--linker=hoisted` 以避免 `.bun` 符号链接
- 通过 extraResources 捆绑 SDK 以绕过 node_modules 排除
- 添加 `bun.lock` 以实现一致的跨平台构建
- 修复 afterPack.cjs 中的正确应用捆绑包名称
- 多个符号链接处理修复用于 Windows 打包
