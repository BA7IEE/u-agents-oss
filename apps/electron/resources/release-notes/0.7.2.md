# v0.7.2 — 提供商预设、岛屿系统与缺陷修复

---

## 新功能

- **岛屿系统** — 将 `Island` 和 `IslandFollowUpContentView` 提取到共享的 `@u-agents/ui` 包中，作为注释后续和内联内容扩展的可复用原语（7c4ba6af, 2432b421, 4397b284）

- **MiniMax 提供商预设** — 添加 MiniMax 作为预配置基础 URL 和模型列表的内置 LLM 连接预设（36cf45d5）

- **Kimi (Coding) 提供商预设** — 添加 Moonshot 的 Kimi Coding 作为内置 LLM 连接预设（c59d9d8d）

- **OpenAI 区域预设** — 添加 OpenAI 欧盟（`api.openai.eu`）和美国（`api.openai.us`）区域 API 端点预设（bfc2be3c）

- **应用级默认思考级别** — 思考级别（关闭/思考/最大）现可设置为跨会话和应用重启持久化的应用级默认值；工作区级覆盖优先（f5593fb1, 7c0f2659）

- **本地开发构建模式** — 新 `CRAFT_DEV_RUNTIME` 构建标志在开发期间从 monorepo 解析 SDK 和拦截器，带平台感知的 bun 回退；添加 `electron:dist:dev:{mac,win,linux}` 脚本（506f2b02）

## 改进

- **延迟 SDK 检查** — Anthropic SDK 和运行时验证从应用启动延迟到会话创建（启动时 `strict: false`，会话开始时 `strict: true`），允许应用即使 SDK/拦截器/Bun 尚不可用也能打开窗口（cc70ce76）

- **暂存类型检查流程** — 预提交钩子现仅对暂存文件触及的包运行有针对性的类型检查，而非完整 monorepo 类型检查（538b12f4）

- **Toast 主题化** — Sonner toast 描述文本和关闭按钮现遵守活动主题令牌而非使用硬编码颜色（59cfeab4, caea757f）

- **分支创建加固** — 新分支的严格 SDK 分叉语义；非空白预检提示防止 Anthropic 分支会话上的 `invalid_request` 错误（9a2f5ed2）

## 缺陷修复

- **Google OAuth 错误错误分类** — 用户点击取消的 `access_denied` 错误显示为"应用被管理员阻止"；修复布尔逻辑（`||` → `&&`），使特殊消息仅在 Google 错误描述提到验证时出现。部分修复 (#300)（f40d2e41, 0ffee7f6, c11819ef）

- **状态图标覆盖被忽略** — 本地状态图标文件名由于缺少目录扫描未被发现；还在图标文件名模式中添加 `.webp` 支持。修复 (#358)（f40d2e41, 0ffee7f6, c11819ef）

- **Pi 提供商路由** — 自定义端点现正确解析 `piAuthProvider` 字段而非需要预设选择。修复 (#363)（f40d2e41）

- **删除后会话仍可访问** — 会话删除现通过 5 秒超时的 DELETE 请求撤销查看器分享链接，防止已删除会话保持公开可访问。修复 (#328)（15e4830e, c11819ef）

- **@提及自动完成空格后中断** — 文件匹配现使用子序列搜索而非前缀匹配，使 `app comp` 正确匹配 `app/components/...`。修复 (#298)（c939d930）

- **CI bun.lock 漂移** — 刷新 `bun.lock` 并在 CI 中固定 bun 版本以防止 `--frozen-lockfile` 失败。修复 (#359)（9e9cebd2, 15e4830e）

- **传输横幅重叠 TopBar** — 重连横幅的重试按钮隐藏在 TopBar 的帮助按钮后；通过将 48px TopBar 偏移提升到共享父容器修复（71abeda4）

- **Windows 上的 Pi 会话目录** — 由于路径分隔符问题，会话文件在 Windows 上创建在错误目录中（d3e83985）

- **Copilot OAuth 子路径** — 修复 Pi 基于 copilot 认证流程的错误 OAuth 回调路径（430c6f3d）

- **连接错误诊断** — 客户端模式现记录在启动时；连接错误消息包含服务器 URL 以便更容易调试（ff7cf0b8）
