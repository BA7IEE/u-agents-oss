# v0.11.0 — 项目与看板任务（Beta）

这是一次以项目化工作流为核心的大版本：工作空间新增“项目”，并通过可持久化任务与看板，把多会话协作组织成更清晰的执行过程。

## ⭐ 项目

- 新增项目列表和项目详情页，可集中管理会话、资产与设置。
- 会话可以绑定项目，并继承项目工作目录。
- 项目的资产清单与限长 `MEMORY.md` 会作为 `<project_context>` 注入会话上下文。
- 会话列表支持按项目分组与筛选。
- 项目可设置独立强调色，工作空间头像与颜色选择器也同步升级。
- 项目绑定状态会实时更新，相关界面已完成多语言适配。

## ⭐ 看板与任务 — Beta

- 新增可拖拽看板，可按项目设置、重命名、着色和排序列，并可为列配置落入状态。
- 新增独立任务编辑器，支持验收标准、标签、结果查看、创建后运行以及从卡片重新运行。
- 复杂任务可拆分为带依赖关系的 `task.yaml` 子任务图，由 Conductor 在多个真实子会话间按依赖顺序执行。
- 子任务进度会合并显示在任务卡片上；执行中断后可恢复。
- 当任务结果未满足验收标准时，可进入检查与修复循环。

> 看板、任务与 Conductor 当前均为 Beta，交互和任务格式仍可能在后续版本调整。

## 新功能

- 后台代理可以选择跨 turn 保持运行，并在完成后唤醒空闲会话、显示结果与运行状态。为避免意外消耗 U-API Token，U Agents 默认关闭此能力；需要时可设置 `U_AGENTS_KEEP_BG_AGENTS_ALIVE=1` 显式开启。旧环境变量仍兼容。

## 改进

- Pi SDK 升级到 0.80.3，移除了 OpenAI 协议连接中会截断长响应的 20 秒 SSE 超时。
- 补齐崩溃页、浏览器工具栏、项目、看板和任务等界面的多语言文案。
- 自动化“测试”不再等待完整 turn 结束，避免误报 30 秒超时。
- 超长会话标签会正确截断，不再撑开侧边栏。
- macOS 本地网络权限说明已加入安装包，授权后可访问局域网 MCP、API 和本地服务。

## 兼容性

- 没有必须迁移的破坏性变更。
- 后台代理跨 turn 常驻在 U Agents 中为显式开启项，不会改变现有默认 Token 消耗行为。
