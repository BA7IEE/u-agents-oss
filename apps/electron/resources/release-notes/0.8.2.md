# v0.8.2 — WebUI OAuth、浏览器控制与搜索可靠性

## 新功能

- **内置浏览器切换** — 新增设置选项以禁用内置 `browser_tool`，当你更喜欢外部浏览器 MCP 或真实已登录的浏览器会话时。（修复 #497）

- **统一 WebUI 源 OAuth** — 基于浏览器的源认证现通过稳定的继电器回调与服务器端完成路由，使 Webui OAuth 流程对 Google、Microsoft、Slack 和 MCP 支持的源更可靠地工作。

- **WebUI 可安装应用资产** — 为浏览器 UI 添加图标、清单和 Apple 触摸图标支持。

- **更快的文件系统密集型任务** — 为昂贵的文件系统操作添加每会话缓存，减少代理回合期间的重复开销。

## 改进

- **WebUI 认证加固** — 用 `jose` 替换手写的 JWT 路径，用 `argon2id` 哈希密码，并为无头/WebUI 认证端点添加全局速率限制器。

- **无头部署文档** — 使用 Cloudflare Tunnel 指南和更清晰的 Docker/主目录故障排除扩展自托管服务器文档。

- **视觉打磨** — 改进应用中的深色模式对比，并与默认主题值对齐样式。

- **发布说明元数据清理** — 修复应用内"新增功能"发布说明中缺失的版本头。

## 缺陷修复

- **WebUI Google OAuth 重定向不匹配** — 通过使用稳定的提供商面向回调（`https://u-agents.u-studio.cn/auth/callback`）并将真实目标继电器通过 state，修复 WebUI 中的 `redirect_uri_mismatch`。

- **搜索可靠性和计数一致性** — 修复了几个搜索回归：更老的会话更可靠地匹配，语法高亮代码块内的跨节点匹配正确找到，徽章计数现与实际高亮匹配对齐，当 `ripgrep` 不可用时 WebUI/远程搜索更优雅地降级。（部分解决 #394）

- **搜索高亮稳定性** — 围绕 CSS 自定义高亮 API 重新设计高亮渲染，避免过时引用、取消的 RAF 和样式表警告。

- **OAuth 回调管道** — 通过服务器引导连接 `oauthCallbackDeps`，使 WebUI 回调完成始终到达正确的服务器端流程。

- **附件过滤** — 扩大 base64 过滤器以捕获附件缩略图，避免误报搜索命中。

- **路由和链接修复** — 修复营销路由并更新下载链接以匹配当前工件命名。

## 破坏性变更

- 无。
