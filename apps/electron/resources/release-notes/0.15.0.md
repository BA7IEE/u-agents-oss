## 新功能

- 更新整体界面，包括侧边栏、输入框、聊天记录、设置页和弹窗。会话状态、标签与操作集中到聊天顶部，窄窗口和触屏布局也做了调整。
- 后台任务显示当前进度，可以查看运行中的输出并停止指定任务。
- 回复中的 Shell 代码块支持发起后台执行，继续遵循当前会话的权限模式。

## 改进

- 升级 Pi SDK 至 1.1.0，更新 Claude Agent SDK；本次测试包不启用额外的后台缓存预热请求。
- 新会话提供快捷提示词，标签中带有的值可以直接编辑。
- Pi 会话中的工具失败会明确传递给模型，并正确触发失败相关的自动化。

## 修复

- 修复 MCP 和 API 数据源调用缺少用途字段而失败的问题。
- Pi 会话不再加载工作目录或全局 Pi 配置中的扩展代码。
- 标题、摘要等后台调用不再附带完整的会话工具。
- 统一标签大小写与去重规则，避免自动化重复触发。
- 修复后台子任务分组、自动化时区、WebUI 深链接及认证输入取消行为。
- 数据源测试失败时，列表与详情页保持一致。

U Agents 继续通过 U-API 调用模型，支持范围取决于当前 Token 的模型清单。
