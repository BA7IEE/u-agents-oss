# v0.2.33 — 简化 OAuth 认证与开发者测试工具

## 新功能

### 简化 OAuth 认证
- U Agents 现专用自己的 OAuth 流程进行认证
- 移除 Claude CLI/Desktop 令牌检测和导入功能
- 有遗留令牌的用户将一次性被提示重新认证
- 更清晰、更可靠的认证体验

### 开发者测试工具
- 新的 `test-token-refresh.ts` 脚本用于 OAuth 令牌测试和调试
- 支持登录、到期模拟、来源检测和迁移测试
- 添加 `--token-only` 标志到全新开始脚本，用于测试入门而不丢失工作区数据

## 改进

### Claude 配置自动修复
- 在 SDK 子进程启动前自动检测和修复损坏的 `~/.claude.json`
- 处理缺失文件、空文件、UTF-8 BOM 编码（Windows）、无效 JSON 和过时的 `.backup` 文件
- 防止由 SDK 将纯文本恢复消息写入 stdout 导致的"CLI 输出不是有效 JSON"崩溃
- 包括 Windows 文件锁定场景的重试逻辑（防病毒、索引器）
- 每进程生命周期运行一次，带错误恢复的重置能力

### OAuth 令牌日志
- 令牌刷新操作现记录到期时间戳以便于调试
- 更清楚地了解令牌生命周期和刷新行为

### 图标缓存健壮性
- 修复缺失工作区图标的空处理
- IPC 调用现正确返回 null 而非为缺失图像抛出
- 为图标缓存边缘情况添加综合测试

### CI/CD 管道
- 新两步发布流程：构建和上传（标签推送时自动）+ 推广到最新（手动工作流）
- 上传清单脚本现可从现有版本工件复制

## 缺陷修复

- 修复 `authType: none`（如 Context7）的源自动激活失败（(#72)）
- `source_test` 现正确设置不需要认证的 MCP、API 和本地源的 `isAuthenticated`
- 修复会话日期分组在应用重启后改变的问题，方法是将 `lastMessageAt` 单独持久化（(#69)）
- 修复空占位符文档，方法是将文档资产复制到 Electron dist（(#70)）
- 通过将缺失脚本添加到白名单修复 OSS `electron:dist:mac` 构建（(#71)）
- 修复工作区图标文件不存在时的潜在崩溃
- 修复缺失工作区图像的 IPC 错误处理
- 修复 `~/.claude.json` 缺失、空、BOM 编码或包含无效 JSON 时的 SDK 子进程崩溃
