# v0.3.2 — 专注模式与 OAuth 改进

通过新的专注模式保持专注。OAuth 流程现更稳健和安全。

---

## 专注模式

帮助您集中工作的新无干扰模式。

### 工作原理

**切换专注**
隐藏侧边栏并最大化您的工作区，以保持专注于当前任务。

---

## 基本认证密码支持

带基本认证的源现可选择要求密码字段。

### 新增内容

**灵活认证**
使用 `passwordRequired: true` 配置基本认证源，在凭证提示中显示用户名和密码字段。支持使用 API 密钥作为用户名和空密码的 API（如 Ashby）。

---

## 改进

### 主题与 UI
- 主题精炼和打磨
- 暗色模式改进——包括图标缓存修复，配置的图标现优先于自动发现的本地文件（(#121)）
- 工作区切换改进
- 集中式菜单结构

### OAuth 与安全
- 符合 RFC 8414 的渐进式 OAuth 元数据发现——修复与 Ahrefs MCP 等 URL 中有多个路径段的服务器的 OAuth（(#152)）
- 从构建中移除内置 Google OAuth 凭证——用户现通过源配置提供自己的凭证
- 在 `source_google_oauth_trigger` 中添加凭证验证检查

### 文档
- 将 Google OAuth 设置文档整合到单个页面
- 添加 `passwordRequired` 参数文档用于基本认证

---

## 安全

- **修复 `STORE_ATTACHMENT` IPC 处理器中的路径遍历漏洞**——恶意 sessionId 值之前可能逃逸工作区目录并在文件系统上的任何位置写入文件（(#142)，由 [@xeloxa] 报告）

---

## 缺陷修复

- **查看器**：修复渲染问题，包括共享会话中的 Mermaid 图表（(#145)、(#108)）
- **EditPopover**：将拖动手柄约束在视口边界内——防止弹出窗口被拖到应用窗口外
- **EditPopover**：修复标题栏拖动干扰弹出窗口拖动手柄
- **安装脚本**：使用 YAML 文件进行校验和——修复 Linux 安装上因缺失 manifest.json 导致的 404 错误
- **Shell**：修复集中式菜单中的 shell 问题
