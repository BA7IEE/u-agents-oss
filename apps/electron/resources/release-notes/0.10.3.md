# v0.10.3 — Claude Fable 5

## 新增功能

- **Claude Fable 5 上线** — Anthropic 当前最强的正式发布模型（2026-06-09 GA）现已进入 U Agents 的 Claude Agent SDK 路径，提供完整 100 万 token 上下文窗口。支持 Anthropic 直连与 AWS Bedrock（us/eu/global 三区 inference profile 变体），模型描述已完成 7 种语言本地化。默认模型仍是 Opus 4.8——Fable 与之并列提供而非取代；同时加入 Pi → Anthropic 桥接的偏好清单（位列 Opus 之后）。由于 Fable 5（及 Mythos 5 一类）始终以自适应思考运行、不接受显式的"关闭思考"选项，思考档位解析器现在把"关闭"和"最小化思考"两种情况映射为低强度自适应思考；Opus、Sonnet、Haiku 的行为字节级不变。（说明：U Agents 的 U-API 预设清单暂未加入 Fable 5 / Opus 4.8——如需使用，可在 newapi 后台配置相应路由后于连接的模型清单中自行添加。）
