# v0.8.8 — 本地模型修复、重试按钮与会话间消息

## 新功能

- **会话间消息** — 新 `send_agent_message` 工具使会话能向其他活跃会话发送消息，实现跨会话协调和代理间工作流。

## 改进

- **简体中文翻译** — 修正并更新了 UI 中的简体中文翻译。

- **本地模型文档** — 澄清了本地模型端点的 `/v1` 路径要求。

## 缺陷修复

- **本地模型设置简化** — 本地模型设置不再在不需要时询问 API 密钥；自动为不需要认证的端点传递占位符密钥。模型选择器中的显示也修复了。

- **重试按钮** — 重试按钮现正确重新发送最后用户消息并正确管理聊天输入焦点。

- **无头服务器上重复的 ConfigWatcher** — 修复了无头 Bun/Linux 服务器上可能导致会话活动后间歇性挂起的重复递归 ConfigWatcher。（修复 #538）

- **思考级别处理器** — `SET_DEFAULT_THINKING_LEVEL` IPC 处理器现正确返回成功响应。

## 破坏性变更

- 无。
