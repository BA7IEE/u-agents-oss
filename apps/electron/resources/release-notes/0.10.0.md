# v0.10.0 — 远程 browser_tool 桥接、浏览器标签按工作区隔离 + #824 basic-auth 修复

## 新增功能

- **远程 browser_tool 桥接到本地浏览器** — 运行在远程工作区（headless 服务器、docker、WebUI）的智能体现在可以端到端驱动用户本地桌面的浏览器。新增 `client:browser:invoke` WS 能力（握手时广告、服务端调用客户端、错误码 `.code` 双向保留），与 `shell.openExternal` 处理 `OPEN_URL` 的方式一致。传输层新增 `hasClientCapability` / `findClientsWithCapability` 路由；Electron 新增 `__browser:invoke` IPC 派发器，带按方法的归属密钥授权、远程调用不复用手动窗口、会话级 `listInstances`、截图跨线转换。`uploadFile` 在桥接上被禁用；`evaluate`（执行任意 JS）由本地 `allowRemoteEvaluate` 设置门控。
  > **U Agents 安全默认**：本应用默认关闭内置浏览器工具（`browserToolEnabled=false`），远程 `evaluate` 默认关闭（`allowRemoteEvaluate=false`），且远程派发器在浏览器工具关闭时拒绝一切远程调用。需要时可在「设置 → 工具」中开启。

- **浏览器标签按工作区隔离** — 之前浏览器管理器是进程全局的，状态变更广播给所有窗口，导致工作区 A 的聊天看到工作区 B 的浏览器标签。现在每个浏览器实例都带工作区标识，状态变更按工作区路由，标签列表按当前工作区过滤。窗口仍各自独立运行——这是 UI 可见性过滤，不是沙箱。字段可选，旧版本容忍缺失值（行为与之前一致）。

## 改进

- **`markdown-preview` 代码块补进富输出文档** — v0.9.6 引入的 `markdown-preview` 块现在补进了在线文档，与 `html-preview` / `pdf-preview` / `image-preview` 并列，方便用户查用法和字段说明。

- **浏览器桥接接线可从服务端日志观测** — 会话管理器新增三行日志，确认引导时 RPC 服务是否就绪、智能体初始化时浏览器转发是否执行。便于仅凭服务端日志诊断远程工作区的浏览器问题。

## 缺陷修复

- **渲染层过滤标签时同时接受本地和远程工作区 id** — 连接远程工作区时，渲染层有两个相关工作区 id：本地 U Agents 窗口的标识、远程服务器的标识。首版隔离过滤只匹配本地 id，导致远程智能体打开的标签（带远程 id）被过滤掉、在顶栏不可见。改为任一 id 匹配即显示。

- **`STATE_CHANGED` 恢复广播给所有客户端；可见性过滤移到渲染层** — 服务端工作区过滤对远程镜像工作区是错的（渲染层的工作区 id 是本地窗口标识，而远程桥接的标签带远程服务器工作区 id，两者永不匹配）。工作区隔离现在完全在渲染层完成。隐私不变——每个本地连接的渲染层都属于同一用户。

- **远程桥接生命周期路径不复用窗口（堵住跨工作区劫持）** — 远程智能体的 `browser_tool open` 此前可能挪用本地会话遗留的未绑定窗口。现在每个远程生命周期调用都不复用，远程会话总是新建窗口（除非已拥有）。

- **未绑定窗口的复用限定在所属工作区（不再"标签从工作区 A 跑到 B"）** — 之前复用匹配任意未绑定的手动窗口，导致工作区 B 的会话挪用工作区 A 的遗留窗口、把它"搬"过去。现在仅当候选窗口工作区为空（真正用户手开的）或与调用方工作区一致时才复用。

- **顶栏手开的窗口继承所在工作区** — 之前顶栏手开的标签默认无工作区、被当成"所有工作区可见"而泄漏到每个工作区。现在传入当前工作区；无工作区上下文的调用方仍回退到广播给所有（安全兜底）。

- **`BrowserInstance` 经 IPC 返回前投影成纯快照** — 本地实例内嵌 Electron 原生引用，经 IPC 返回时结构化克隆会抛 "An object could not be cloned"。现在只输出声明字段的纯快照。

- **`source_test` 对 basic-auth 凭证做 base64 编码** — 之前验证把原始凭证值直接塞进 `Authorization` 头，导致 basic-auth source 对每个 provider 都 401。现在像运行时一样解析 JSON 凭证并 base64 编码，旧的已编码值原样透传。修复 #824。

## 破坏性变更

- 无。浏览器实例 DTO 上的工作区 id 字段可选，旧渲染层和旧智能体容忍缺失值（行为与 0.10.0 之前一致）。

## 备注

- **本版主题是远程浏览器桥接 + 浏览器标签按工作区隔离**，不升级底层 SDK，向后兼容。
- **U Agents 安全加固**：针对"远程驱动本地浏览器"这一新能力，本应用默认关闭浏览器工具、远程 evaluate 默认关闭，并在派发器入口加了总闸——确保默认安全，需要时用户可在设置中开启。
