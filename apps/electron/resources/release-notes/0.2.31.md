# v0.2.31 — 工作流状态徽章、内联差异查看器与 TurnCard 展开持久化

## 新功能

### 工作流状态徽章
- 会话现显示其工作流状态作为标签旁边的徽章
- 点击通过下拉菜单更改状态
- 状态选择可在 # 自动完成菜单中获得
- 状态在会话切换之间持久化

### 内联差异查看器
- Markdown 中的差异代码块现渲染为丰富的并排可视化
- 渲染失败时自动回退到纯代码块

### TurnCard 展开持久化
- 回合卡片的展开/折叠状态在会话切换之间持久化
- 状态存储在 localStorage 中，带 LRU 边界（最多 100 个会话）

## 改进

### 统一版本管理
- 合并版本管理以使用 package.json 作为唯一事实来源
- 移除 app-version.ts 而支持直接读取 package.json
- 构建脚本、CI 工作流和运行时代码都使用相同的版本来源
- 简化发布工具（移除 sync-version.ts）

### 窗口状态处理
- 改进窗口状态恢复的 URL 处理
- 移除不必要的 URL 清理（查询参数被安全提取和重建）

### Windows SDK 设置
- 更好地检测缺失 .claude/skills 目录的错误和用户友好说明

## 缺陷修复

- 修复 app-version.ts 和 package.json 之间的版本不匹配导致错误的发布清单
- 将回合卡片状态从全局 Jotai atoms 移到会话特定的 localStorage 以获得更好的隔离
