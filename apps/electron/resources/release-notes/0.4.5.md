# v0.4.5 — Slack 令牌修复与 Copilot 捆绑

修复 Slack 源由于令牌刷新系统错误处理不可刷新 OAuth 令牌而无法使用的问题，以及 Copilot CLI 捆绑改进的热修复版本。

---

## 缺陷修复

- 修复不可刷新 OAuth 令牌（Slack）被 `ensureFreshToken()` 破坏的问题——没有 `refreshToken` 的令牌（如 Slack bot 令牌）现按原样返回，而非落入失败的刷新并将源标记为 `needs_auth`（e358e414）
- 修复重新认证后刷新冷却时间未清除的问题——重新认证源后，5 分钟冷却时间现立即清除，因此源无需等待即可使用（e358e414）
- 修复 Windows 上的 Copilot CLI——将 `copilot.exe` 添加到 `extraResources` 以避免 electron-builder 打包期间的 EBUSY 文件锁定（d4cda5f2）
- 将 `copilot` 添加到 LLM 提供商类型验证器 schema（d4cda5f2）

## 构建与 CI

- 为所有平台（macOS arm64/x64、Linux、Windows）的 CI 工作流添加 Copilot CLI 捆绑验证（d4cda5f2）
- Copilot CLI 原生二进制文件现按平台正确捆绑在构建脚本中，带大小验证（d4cda5f2）
