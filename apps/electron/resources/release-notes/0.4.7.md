# v0.4.7 — 多层技能解析修复

针对关键问题的有针对性缺陷修复——来自全局（`~/.agents/`）和项目级（`.agents/`）目录的技能尽管在 UI 中可见但无法调用。

---

## 缺陷修复

- **全局/项目目录技能使用"未知技能"失败** — UI 通过 `loadAllSkills` 发现三层（全局、工作区、项目）的技能，但 SDK 后端仅将工作区目录注册为插件。全局和项目级技能显示为可调用，但使用时返回"未知技能"。通过将所有三层技能目录注册为 SDK 插件修复，重写 `qualifySkillName` 以根据每层解析正确的插件前缀，并修复 UI 提及菜单以根据技能来源使用正确的插件限定符（0fb687d5）
- **功能标志未捆绑在打包应用中** — `feature-flags.ts` 缺失于构建脚本的复制步骤，导致打包构建（尤其是 Windows）无法加载编译时功能标志（6268fefd, c44899cb）

## 改进

- **GitHub 问题模板** — 在 OSS 仓库中添加了错误报告和功能请求的结构化模板（35123388）
