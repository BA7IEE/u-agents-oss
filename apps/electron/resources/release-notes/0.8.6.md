# v0.8.6 — 分块会话传输与自定义端点图像支持

## 新功能

- **分块会话传输** — 大型会话现可通过分块 WebSocket RPC 在工作区之间传输，使用 base64 编码、SHA-256 校验和及逐块重试。避免了之前导致传输静默失败的 WebSocket 消息大小限制。传输进度在发送按钮上显示为紫色 LED 边框动画，跨多会话批量操作使用规范化进度跟踪。

- **自定义端点图像输入** — 自定义端点模型（如**Gemma 4** via Ollama）现可接收图像附件。之前图像被静默丢弃，因为自定义模型硬编码了仅文本输入。**重要：**自定义端点默认仍为纯文本——你必须在连接配置中设置 `supportsImages: true` 以启用图像输入。见[自定义端点文档](https://u-agents.u-studio.cn/docs/reference/config/custom-endpoint#image-input-for-custom-endpoints)查看每模型和全端点示例。（修复 #525）

## 缺陷修复

- **会话传输重连加固** — 工作区传输期间改进错误恢复，具有独立的 base64 块解码、更大的块大小（2MB）和健壮的重连处理。

- **传输使用了错误的工作区 ID** — 会话导出现正确使用源工作区 ID 而非目标，修复了传输期间不正确的路由。

- **内联聊天中的凭证提示** — EditPopover 内联聊天中的凭证和权限提示现正确工作。

- **睡眠/唤醒后消息丢失** — PC 睡眠/唤醒后过时 WebSocket 重连期间消息消失的额外修复。

- **发送按钮布局** — 恢复取消和发送按钮之间的适当间距以匹配对话框页脚模式。

## 破坏性变更

- 无。
