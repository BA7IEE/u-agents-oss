# v0.8.3 — 会话自我管理、紧凑模式与自动化可靠性

## 新功能

- **会话自我管理工具** — 代理现可通过 `set_session_labels`、`set_session_status`、`get_session_info` 和 `list_sessions` 设置自己的标签、状态和查询其他会话。实现代理完成工作并发出完成信号的自我关闭自动化工作流。

- **紧凑模式 UI** — 为权限模式、附件、源和工作目录选择添加紧凑模式工具栏控制，带基于抽屉的选择器，外加紧凑聊天和会话信息布局。

## 改进

- **遗留提供商清理** — 移除已弃用的提供商类型并改进连接设置中的错误处理。

- **Docker 构建性能** — 用有针对性的 `find` 命令替换一刀切的 `chmod -R`，显著加快 Docker 镜像构建。

- **Docker 多架构 CI** — 发布和推广工作流现构建多架构 Docker 镜像。

## 缺陷修复

- **fs.watch 在空闲会话上恢复元数据** — 修复了文件系统监视器在空闲会话上恢复编程元数据写入（标签、状态）的竞争条件。

- **陈旧的服务器锁文件** — 处理 Docker 容器重启时陈旧的 `.server.lock` 文件，使服务器干净启动。（部分解决 #493）

- **无头服务器上自动化不触发** — 在启动时急切初始化自动化系统而非延迟，使计划和事件驱动的自动化在首次运行时工作。（部分解决 #491）

- **setSessionStatus 静默失败** — 正确等待异步 `setSessionStatus` 调用以显示错误而非静默吞下。

- **针对其他会话的会话工具** — `set_session_labels` 和 `set_session_status` 现可正确针对调用方以外的会话。

- **会话工具验证** — 标签 ID 和状态 ID 现在应用前验证，防止无效值的隐晦错误。

- **会话工具显示名称** — 会话管理工具现 TurnCard UI 中显示人类可读的名称。

- **连接设置上的模型刷新** — 配置新连接后等待模型列表刷新，防止模型列表过时。

- **忽略协作者偏好** — 为 git 提交 trailer 尊重 `includeCoAuthoredBy: false` 用户设置。（修复 #500）

- **本地文件 URL 路由** — 修复 markdown 路由处理 `file://` URL，使本地文件链接正确渲染。（部分解决 #416）

- **Toast 文本截断** — 允许 toast 通知描述最多换行 2 行，而非截断。

- **Docker Compose 镜像标签** — 在 Docker Compose 配置中将默认服务器镜像更新为 v0.8.2。

## 破坏性变更

- 无。
