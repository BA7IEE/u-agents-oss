## 新功能

- MCP 数据源支持列出和读取资源、列出和获取提示词，Claude 与 Pi 会话使用相同能力。
- 项目记忆增加追加工具，减少多个会话互相覆盖笔记的情况。

## 改进

- 停止当前回复时，已启动的后台代理、工作流和命令可以继续运行并报告结果。
- 改进隐藏浏览器窗口的点击、键盘操作、下拉框与截图刷新。
- 并行会话可以共用同一次数据源登录；支持的数据源会先尝试刷新过期凭据。
- 减少误报的浏览器安全验证提示，简化截图与日志输出。
- 浏览器输入的密码会在结果及保存的记录中隐藏。
- 使用 Shell 阅读数据源指南也能满足先读指南的要求。

## 修复

- 中途停止的任务步骤不再被误记为完成，后续步骤会等待所需结果。
- 超出大小限制的附件在发送前提示文件名称和限制。
- API 数据源按用户填写的请求头名称发送凭据，同时继续拒绝将服务账户 JSON 拆成请求头。
