# v0.8.1 — 远程恢复、Docker Compose 与稳定性修复

## 新功能

- **远程工作区恢复流程** — 断开的远程工作区现可直接从工作区切换器重新连接。重连 UI 预填充当前 URL，让你更新 URL 或令牌、测试连接并保存，无需移除和重新创建工作区。

- **基于 Docker 的服务器部署** — 添加 `docker-compose.yml` 以简化无头部署，Compose 默认为 GHCR 服务器镜像，并将 Web UI 资产烘焙到 Docker 镜像中，因此一个服务可同时覆盖无头和浏览器访问。

- **Web UI 文件缩略图** — 浏览器客户端现通过 `readFileDataUrl` 回退加载图像缩略图，而非依赖仅 Electron 的 `thumbnail://` URL。

## 改进

- **一致的标签排序** — 标签选择器现侧边栏、`#` 自动完成、右键菜单、批量标签菜单和过滤器下拉菜单使用相同的字母排序。

- **技能源清晰度** — 项目级技能现可在 SkillInfoPage 中正确解析，更清晰地显示其来源，项目管理的技能不再作为可删除项从应用中提供。

- **工件命名一致性** — 构建脚本、CI 工作流、安装脚本、文档和下载链接现一致使用复数 `U-Agents-*` 工件命名。

- **远程会话传输清理** — 传输到远程工作区的会话现删除在目标服务器上不存在的陈旧工作目录路径。

## 缺陷修复

- **远程工作区稳定性** — 修复了多个远程工作区故障模式：远程服务器关闭时应用不再挂在启动画面上，减少重连横幅闪烁，重连等待真实连接，Claude OAuth/设置调用在需要时路由到远程工作区服务器。

- **会话加载错误处理** — 非传输会话加载失败现显式浮出水面，而非掩盖为空工作区状态。

- **图像和附件处理** — 大附件现使用分块 base64 编码，当 `sharp` 不可用时图像尺寸检查非致命，缺失处理支持的图像与无效图像区分开来。

- **Pi 子进程弹性** — 损坏的 stdout 管道不再触发失控的重复错误洪水，子进程错误去重在生命周期边界之间正确重置。

- **Web UI / 无头兼容性** — Web UI 现 WebSocket 握手前解析默认工作区，并在连接到无头服务器时避免调用仅桌面的 RPC 通道。

- **Docker 默认值** — 修复了围绕 `.u-agents` 目录所有权、端口和自托管服务器设置卷行为的 Dockerfile 和 Compose 默认值。

## 破坏性变更

- 无。
