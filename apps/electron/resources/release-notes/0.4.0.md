# v0.4.0 — LLM 连接、Codex 支持、工作区默认值

多连接 AI 设置、Codex/OpenAI 支持、每工作区默认值和文档升级。

---

## LLM 连接（多提供商）

U Agents 现支持多个 **LLM 连接**：

- 添加多个提供商（Anthropic、OpenRouter、Codex/OpenAI 等）
- 独立验证和管理每个连接
- 会话在第一条消息后锁定到连接

## Codex / OpenAI 支持

通过 **Codex** 使用 OAuth 连接 OpenAI，并与 Anthropic 连接并行运行 Codex 支持的会话。

## 每个工作区的默认连接

工作区现可设置自己的**默认 LLM 连接**，覆盖该工作区中新会话的全局默认。

## 工作区特定的默认主题

每个工作区可通过 `defaults.colorTheme` 设置**默认主题**，便于视觉上区分上下文。
