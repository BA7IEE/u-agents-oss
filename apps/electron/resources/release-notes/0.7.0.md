# v0.7.0 — CLI、无头服务器与架构重构

---

## CLI

运行代理会话的新终端客户端——无需 GUI。

- **`u-agents-cli run`** — 直接从终端启动代理会话，带提示输入和流式输出
- **多提供商支持** — 从 CLI 选择多个 LLM 连接和模型
- **CI 工作区支持** — 以编程方式创建和管理工作区
- **`--validate-server`** — 验证服务器配置，带美化的诊断输出
- **重新设计的微调器** — 在代理思考期间保持可见，以获得更好的终端 UX

### 为什么很酷
这是迈向 U Agents 完全编程控制的第一步。编写脚本化代理工作流，集成到 CI/CD 管道，或在远程机器上无头运行会话。部分解决 (#343)。

## 无头服务器

将 U Agents 作为独立服务器运行，无需 Electron 桌面应用——部署在任何机器上，从任何客户端连接。

- **独立 Bun 服务器** — 无 Electron 运行的无头入口点，从捆绑包中移除 sharp
- **TLS 支持** — 带自动证书处理的安全远程连接
- **多平台构建脚本** — Linux、macOS 和 Windows 的分发打包
- **通过环境变量的远程模式** — 通过环境变量配置无头操作
- **瘦客户端连接状态** — 客户端中的 WebSocket 连接状态和失败横幅

### 为什么很酷
在远程服务器上部署 U Agents 并从任何地方连接。在家庭实验室、云 VM 或 CI 运行器上运行它。瘦客户端模式意味着浏览器 UI 保持轻量，而所有繁重工作在服务器端完成。部分解决 (#291)。

## 传输与架构

整个进程间通信层已从零重建。

- **仅 WebSocket RPC** — 用 WebSocket RPC 替换所有通信的 Electron IPC，实现远程操作
- **双向 RPC** — 类型化推送事件、服务器拥有的 OAuth 令牌管理
- **Server-core 提取** — 14 个核心处理器、会话管理、服务和领域实用程序提取到 `@u-agents/server-core`，跨 Electron 和无头重用
- **协议形式化** — 通道、DTO 和事件映射提取到 `@u-agents/shared/protocol`，带 wire 格式稳定性测试
- **双脑清理** — 移除死处理器/会话副本，添加 `IWindowManager` 和通道广告

### 为什么很酷
这是使 CLI、无头服务器和未来远程/移动客户端成为可能的架构基础。架构现在干净地分离为可重用的 server-core 逻辑和平台特定外壳（Electron、Bun 服务器、CLI）。
