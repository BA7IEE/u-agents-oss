## U Agents 更新说明

- 收紧探索模式下的只读检查，避免把名称中包含读取动词的写操作误判为只读。
- “始终允许”按具体审批范围记忆；子会话不能获得比父会话更宽的权限。
- 改进计划提交、数据源登录和源激活后的会话续接，减少重复消息。
- 大型 MCP 结果在进入模型前处理；长时间运行的工具持续更新状态，不再反复新增记录。
- 修复停止后重新执行、连续发送时的会话文件冲突及自动化自触发。
- 保留 U-API 动态模型、生图授权和手动更新入口；Pages 支持本地展示与批准的 API/MCP 操作。
- 本轮不开放独立决策模型、Guarded 模式、语义自动化条件、Pages 脚本、定时刷新和公开发布。已有 Guarded 会话按编辑前确认处理。
