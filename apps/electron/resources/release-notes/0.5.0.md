# v0.5.0 — 使用任意 LLM 提供商

---

## 新提供商连接

- **Codex · ChatGPT Plus** — 使用你的 ChatGPT Plus 或 Pro 订阅直接使用 OpenAI 的 Codex 模型（(#2)、(#44)）
- **GitHub Copilot** — 一键设备代码认证连接你的 GitHub Copilot 订阅（(#49)）
- **Google AI Studio** — 使用你的 Google AI Studio API 密钥使用 Gemini 模型。内置原生 Google Search grounding 的一级支持。（(#240)）
- **OpenRouter、Ollama 和自定义端点** — 为任何 OpenAI 兼容提供商自带 API 密钥——OpenRouter、Ollama 或任何自定义端点（(#14)、(#27)）
- **可搜索模型选择器** — 当提供商有很多模型时，通过带智能默认的可搜索下拉菜单从三层（最佳、平衡、快速）中选择

## 改进

- **提供商图标** — 连接设置现显示上游提供商的标志和名称，使你一目了然地区分连接
- **MCP 源适用于所有提供商** — 你连接的 MCP 源现代理到非 Anthropic 后端，因此 Linear、GitHub 和 Slack 等工具无论使用哪个 LLM 都可用
- **会话列表重新设计** — 用于更简洁、更一致 UI 的可复用实体列表原语
- **技能元数据** — `requiredSources` 和 `icon` 现显示在技能信息页面并被验证接受（(#290)、(#249)）
- **Copilot 模型过滤** — 仅显示组织策略启用的模型（92200095）

## 缺陷修复

- **状态图标颜色** — 恢复右键上下文菜单中的颜色（6fa9b85b）
- **Windows 路径** — 修复工作区 slug 提取中的反斜杠处理（3d22e75f）
- **模型层保留** — 你选择的模型不再被提供商默认值静默覆盖（1ddfe96f）
- **Windows 构建** — 修复原生模块解析（koffi）、Vite OOM 和拦截器文件打包，以实现可靠的 Windows 构建（0ae044a2、ff791b03、258e3e39）
- **Windows 运行时** — 升级捆绑的 Bun 1.3.5 → 1.3.9 以修复 Windows 崩溃（c4f46abc）
- **Pi SDK 0.55.0** — 升级 Pi SDK 以修复流式冻结和格式错误的 OpenAI 部分块 JSON（718d4ad6）
- **安装脚本** — 修复 Windows 和 macOS/Linux 安装脚本，使其无需版本端点工作；脚本现直接获取 YAML 清单（(#273)、(#276)）

## 安全

- **Web-fetch 加固** — 防止 SSRF、无界读取和其他边缘情况（3904a786）
- **探索模式** — 阻止 `find -exec` 和类似的 shell 转义向量（(#272)）

## 基础设施

- **Cloudflare 迁移** — 将 R2 bucket 和 Workers 迁移到新 Cloudflare 账户（55bb899e）
- **CI** — Windows 构建现使用 `windows-latest` 运行器（c4ac80a6）

## 破坏性变更

- **Codex/Copilot 后端合并** — 独立的 Codex 和 Copilot 后端已被统一的 Pi SDK 后端替换。现有的 Codex 和 Copilot 连接需要通过新入门流程重新配置。
- **移除通过 Pi 的 Claude OAuth** — 通过 Pi 后端使用 Claude 订阅的选项已因 Anthropic ToS 合规性而移除。请改用直接的 Claude Pro/Max 连接。
