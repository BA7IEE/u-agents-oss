# v0.7.5 — 网络代理、Webhook 与社区修复

---

## 新功能

- **网络代理支持** — 直接从应用设置配置 HTTP/HTTPS 代理及绕过规则。代理引擎通过 `undici` ProxyAgent 实例路由流量，遵守 `NO_PROXY` 规则，并配置 Node 和 Electron 浏览器会话。（46049d28, 0ed01c48, 81d1b1c3, 0da3f265）

- **自动化 Webhook 动作** — 自动化现可触发 HTTP webhook，带可配置认证、表单负载、响应捕获、重放和带指数退避的持久重试。（993c75ce, 588aab6c）

- **Gemini 3.1 Flash Lite** — 添加到 Google AI Studio 首选默认值。感谢 (#357) 中的建议。（e36e9a22）

- **解散工作目录历史项** — 每个最近目录条目上悬停可见的 X 按钮以从历史中移除。感谢请求此功能的 (#346) 中的 @jjjrmy 和 (#391) 中的 @jonzhan。（3bd55d6d）

## 改进

- **历史截断** — 将所有历史字段截断整合到单一 `HISTORY_FIELD_MAX_LENGTH` 常量，而非分散硬编码限制（8689a1d4）

- **源文档** — 在指南中添加 Collections 部分，强调嵌套标题 + 属性项目格式（0837afa0）

## 缺陷修复

- **MiniMax CN 认证** — 移除错误的 `minimax-cn → minimax` 别名，为 Pi 提供商添加轻量直接 HTTP 测试，并剥离 MiniMax 前缀以兼容 CN API。感谢报告的 (#396) 中的 @Kathie-yu 和 (#386) 中的 @RimuruW。修复 (#396)。（612c0e7e）

- **消息中的内联代码** — 徽章（源、技能、文件）之间的文本现通过 Markdown 组件渲染，恢复内联代码、粗体、斜体和链接。感谢报告 (#378) 中的 @linusrogge。修复 (#378)。（e7f88a38）

- **Zod/JSON Schema 直通** — 默认 Zod 对象 schema 为 `.passthrough()` 以匹配 JSON Schema 语义，其中 `additionalProperties` 默认为 `true`。同时在 MCP 代理工具 schema 往返中保留 `additionalProperties`。修复具有松散类型 schema 的工具静默丢失字段的问题。（cf4b6ac1, 42c173cf）

- **自签名 TLS 证书** — 接受配置远程服务器源的自签名证书，修复 `wss://` 连接上的 `ERR_CERT_AUTHORITY_INVALID`（7148ebec）

- **瘦客户端模式下的文件附件** — 回形针按钮现使用浏览器原生的 `FileReader` API 而非服务器端 `fs.readFile()`，修复客户端和服务器文件系统不同时的静默失败（680cd197）

- **URL 链接化** — 从产生损坏链接的链接化 URL 中剥离尾部 markdown 字符（`**` 等）（24385e78, 65b8f350）

- **自动化动作徽章** — 侧边栏现根据实际动作类型显示正确的"提示"/"Webhook"徽章，而非硬编码"提示"（dc422573）

- **打包服务器路径回退** — 为 `extraResources` 输出布局不同的构建添加 `dist/resources` 回退（edc5f61f）

- **`$CRAFT_EVENT_DATA` 缺少标签** — 所有自动化事件负载现包含会话的当前 `labels` 数组，使 webhook 和脚本可访问标签数据。修复 (#406)。（0f98f090）

- **多选非相邻会话** — Cmd 点击现始终切换选择（标准 OS 行为）；在新面板中打开移到 Cmd-Shift 点击。修复 (#404)。（d4d7aff1）

- **@ 提及带空格自动完成** — 文件提及查询现允许空格（如 `@app availability.md`）。菜单在空格产生无匹配时以 Slack 风格自动关闭。感谢报告 (#398) 中的 @alexzadeh。修复 (#398)。（1d063177）
