# U Agents v0.11.1 — 2026-07-12

## 新增

- 同步上游 `v0.11.1`，Pi SDK 升级至 `0.80.6`。
- 接收 GPT-5.6 Luna、Terra、Sol 的原生推荐顺序与 `ThinkingLevel.max` 透传。
- U-API 继续使用 Token-only 动态模型发现与真实探活降级，不开放上游 provider 连接入口。

## 修复

- Windows 打包入口统一改用 `bunx`，避免 npm `EOVERRIDE` 阻断。
- 发布后源码收尾修复 Electron lint 的 7 个 error：统一 Kanban/状态组件阴影 token，并让项目目录打开操作经过 `AppShellContext.onOpenFile`。

## 发布产物

- macOS Apple Silicon：`U-Agents-arm64.dmg`，SHA-256 `a5fe86d6204b9c5e3dc24a3ef9ef77aa5ab30ead0eee0cd46b833181a50f670d`。
- Windows x64：`U-Agents-x64.exe`，SHA-256 `5c5902871bcc24fe3e13ed2b9c626e59b0427c64448fafa7eeb0bf25b5e1745f`。
- 腾讯 COS 的 `/latest`、`latest-mac.yml`、`latest.yml` 与 `/v0.11.1/manifest.json` 已完成在线核验；清单中的 URL、文件大小与实际产物一致。

## 已知问题

- macOS 产物使用 adhoc 签名，尚未完成 Apple Developer ID 签名与公证。
- v0.10.3 起不再发布 macOS Intel 安装包；Intel 用户最后可用版本为 v0.10.0。
- Electron lint 仍有上游既有 warning，但本版本收尾后为 0 error，不阻塞 CI。

## 合规与发布边界

- 本版本基于 Craft Agents OSS，遵循 Apache 2.0 署名与 `NOTICE` 要求。
- OAuth Source 首次授权仍可能短暂出现 `agents.craft.do`；详见 [`LEGAL.md` §5](../../LEGAL.md#五已知白标瑕疵已被开发者接受)。
- 本版本不发布 standalone server、CLI、WebUI 或 Viewer 分发入口。
